Faça um personagem tremer

Às vezes é útil fazer uma personagem parecer que está a tremer.
Há algumas formas de conseguir isso.

Podemos usar @Phrase/offset com @Random e @Time Para que isso aconteça.

\
offset: 0m … ∆ Tempo() … Aleatório(-0.1m 0.1m)
Frase('Olá' desvio: Local(offset 0m))
\

 Isto cria um valor chamado \offset\ que muda para um novo valor aleatório sempre que o relógio avança.
Depois, usa esse deslocamento para mostrar o @Phrase deslocado por essa quantidade.

Se quiséssemos controlar a vibração com mais precisão, poderíamos utilizar um @Sequence Para criar uma animação de tremor aleatório que se repete.

\
Frase('Olá' descansar: Sequência({
			0%: Pose(desvio: Local(Aleatório(-.2m .2m)))
			15%: Pose(desvio: Local(Aleatório(-.2m .2m)))
			60%: Pose(desvio: Local(Aleatório(-.2m .2m)))
			75%: Pose(desvio: Local(Aleatório(-.2m .2m)))
		} 0.1s))
\

 Este exemplo simplesmente escolhe valores aleatórios uma única vez, mas transforma-os numa sequência repetida.
