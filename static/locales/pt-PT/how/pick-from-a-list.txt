Escolha um item aleatório de uma lista.

Quer que o seu projeto o surpreenda a cada execução? Faça uma lista de opções e escolha uma com @Random.

@Random pode dar-nos um número aleatório, e uma lista pode ser consultada por número com \[n]\.
Junte tudo para escolher um emoji aleatório:

\
emojis: ['🌈' '🌟' '🎈' '🦄' '🍩']
Phrase(emojis.random())
\

 Também pode usar @Random com dois números, que escolhe um número inteiro entre eles.
Por exemplo, para escolher um / novo / emoji aleatório a cada segundo, junte @Time e um @Reaction:

\
emojis: ['🌈' '🌟' '🎈' '🦄' '🍩']
pick: emojis[1] … ∆ Time(1000ms) … emojis[Random(1 emojis.length())]
Phrase(pick)
\

 Cada tique de @Time, o @Reaction escolhe uma nova surpresa.
