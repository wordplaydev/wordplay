Mostrar opções selecionáveis

Por vezes, quer mostrar várias opções no ecrã e fazer algo com a escolha do público. Para isso, precisamos de duas coisas:

• Um ou mais @Phrase que estão marcados como selecionáveis e têm um nome único (por exemplo, \Phrase('opção 1' selecionável nome: 'um')\)
• Uma @Choice, que muda para o nome @Phrase escolhido mais recentemente.

Por exemplo, aqui mostramos três opções, cada uma com um nome único.

\
option: Choice()

Group(
	Stack() [
		Phrase('opção 1' selecionável nome: 'um')
		Phrase('opção 2' selecionável nome: 'dois')
		Phrase('opção 3' selecionável nome: 'três')
		Phrase(option)
	]
)
\

 Sempre que um for escolhido, o último @Phrase Mostra o nome selecionado.

Pode utilizar este padrão para executar ações em resposta a uma escolha. Por exemplo, poderíamos modificar o projeto acima para exibir um emoji secreto com base na escolha:

\
option: Choice()

option = '' ?
	Group(
		Stack() [
			Phrase('opção 1' selecionável: ⊤ nome: 'um')
			Phrase('opção 2' selecionável: ⊤ nome: 'dois')
			Phrase('opção 3' selecionável: ⊤ nome: 'três')
		]
	)
	Phrase(
		{
			'um': '😡'
			'dois': '🏀'
			'três': '❤'
		}{option} ?? '?'
	)
\

 O @Choice começa como um @Text vazio, e por isso, quando o projeto é iniciado, verificamos isso e mostramos as três opções.
Depois de fazer uma escolha, ela passa a ser um dos três nomes @Phrase .

Para mostrar um emoji com base na escolha, podemos usar um @Map para converter o nome num emoji secreto.
Quando obtemos um valor de um @Map, se não houver correspondência, o resultado é \ø\, por isso usamos o \??\ para usar por predefinição \'?'\ se a opção não estiver no mapa. 
Neste caso, isso nunca pode acontecer, mas não somos suficientemente inteligentes para o saber!
