Faça várias cópias de uma personagem.

E se quisermos dez gatos, ou cem estrelas, mas não quisermos escrevê-los todos?
Podemos pedir a uma lista que faça cópias por nós com @List/translate.

Se começarmos com o número \10\ e o converter com \→ []\, obtemos uma lista de dez números de 1 a 10.
Depois usamos @List/translate para transformar cada número num @Phrase:

\
Group(Row() (10 → []).translate(ƒ() Phrase('🐈')))
\

@List/translate Chamamos a nossa pequena função uma vez para cada item e recolhemos os resultados numa nova lista.

Para que cada cópia seja um pouco diferente, utilize o número que a tradução nos dá:

\
Group(Row('|' 0.2m) [:1‥8].translate(ƒ(n) Phrase('⭐' tamanho: n × 0.5m)))
\

 Cada estrela é maior que a anterior, porque \n\ vai de \1\ para \8\.
