Empilhe os caracteres de cima para baixo.

Se um @Row é para lado a lado, pelo que um @Stack É de cima para baixo.
@Stack Coloca cada caractere abaixo do anterior, como uma torre.

\
Grupo(Monte() [
    Frase('um')
    Frase('dois')
    Frase('três')
])
\

 Tal como um @Row, uma @Stack também pode ter um alinhamento e um espaçamento interno.
Experimente alinhar tudo pelo lado esquerdo:

\
Grupo(Monte('<' 0.25m) [
    Frase('🐣 pequeno')
    Frase('🐥 médio')
    Frase('🐔 grande')
])
\

 O \'<'\ significa / alinhar tudo pelo lado esquerdo /.
Também pode experimentar \'|'\ para o centro ou \'>'\ para o lado direito.
