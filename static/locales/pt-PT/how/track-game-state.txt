Manter registo do estado do jogo

A maioria dos jogos acompanha várias coisas à medida que o jogo avança: pontos, posições dos jogadores e outros detalhes são todos importantes.
Sempre que há uma entrada, esse estado muda, e depois queremos mostrar uma nova saída, em resposta.

Um padrão geral para qualquer jogo faz três coisas:

• Defina uma estrutura de dados de estado do jogo, para guardar todo o estado do jogo
• Defina uma reação que cria um novo estado do jogo com base no estado anterior, sempre que há uma nova entrada
• Crie um @Stage com @Group e @Phrase para mostrar o estado do jogo

Por exemplo, imaginemos um jogo simples que consiste em escrever palavras secretas numa caixa de texto, e ganhar um ponto cada vez que se adivinha uma palavra secreta:

\
•Game(secrets•[''] points•#)

state: Game(['gato' 'cão'] 0) … state.secrets.has(Chat()) … state.points: state.points + 1

Stage(
    state.points = state.secrets.length() ? 
        [ Phrase("ganhou!")]
        [ Group(Stack() [ Phrase("adivinhe as minhas palavras secretas") Phrase(`\state.secrets.length() - state.points\ mais segredos`)])]
)
\

 Vamos analisar isto passo a passo.

• A primeira linha, \•jogo(segredos•[''] pontos2•#)\ diz, / Crie uma estrutura de dados chamada \Game\ que guarda uma lista de segredos e pontos /. O \['']\ significa / uma lista com qualquer número de palavras /. Se quiser, em vez disso, uma lista com um comprimento exato, pode indicar um tipo para cada lugar nela: \[# '']\ é uma lista de duas coisas, um número e depois uma palavra.
• A segunda linha diz / O estado do jogo começa com uma lista de segredos e zero pontos. Sempre que o \Conversa\ muda, se a palavra introduzida estiver na lista de segredos, então cria um novo estado do jogo com os pontos aumentados em um /.
• Sempre que o programa é reavaliado (quando o \Conversa\ muda), mostra um palco. Se o número de pontos for igual ao número de segredos, mostra um palco de vitória. Caso contrário, mostra uma indicação e o número de segredos que faltam.

Este exemplo tem alguns problemas:

• Se o jogador adivinhar uma palavra secreta várias vezes, ganha mais pontos! O nosso estado do jogo pode também precisar de lembrar o que já foi adivinhado, para que cada palavra só conte duas vezes.
• Se o jogador introduzir várias palavras, isso deve contar?

Estados do jogo e atualizações do jogo mais sofisticados ajudar-nos-iam a tratar destes casos.
