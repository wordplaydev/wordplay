ספרו כל עוד הזמן עובר

פרויקטים רבים צריכים משהו שגדל עם הזמן — שעון עצר, ניקוד, או ספירה לאחור.
אפשר לבנות מונה בעזרת שילוב של זרם @Time עם @Reaction.

ה @Reaction מורכב משלושה חלקים: ערך התחלתי, דבר שעוקבים אחריו, וערך חדש כשהדבר הזה משתנה.
כאן אנחנו מתחילים ב־ \0\, עוקבים אחרי @Time, ומוסיפים אחד בכל פעם שהשעון מתקתק:

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 בכל שנייה, @Time נורה, @Reaction שם לב בעזרת \∆ Time(1000ms)\, ו- \count\ הופך ל- \count + 1\.
ה \→ ''\ בסוף הופך את המספר לטקסט כדי ש- @Phrase יוכל להציג אותו.

ניתן להשתמש בכל קלט שתרצו, לא רק בזמן. מונה זה סופר את מספר הלחיצות על Button():

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 בכל פעם ש @Button שינויים בזרם בלחיצה או הקשה, הספירה עולה באחד.

track-points, pick-from-a-list
