ゲームの状態を記録しよう

ほとんどのゲームは、進むにつれていろいろなものを記録します。得点、プレイヤーの位置、その他の情報がどれも大切です。
入力があるたびに状態が変わり、そのたびに新しい出力を表示したくなります。

どんなゲームにも通じる基本パターンは、次の3つのことをします。

・すべてのゲームの状態を保存する、ゲーム状態のデータ構造を定義する
・新しい入力があるたびに、前のゲーム状態をもとに新しいゲーム状態を作るリアクションを定義する
・ @Stage と @Group と @Phrase を作って、ゲームの状態を表示する

例えば、テキストボックスに秘密の言葉を入力して、当たるたびに得点がもらえる、というシンプルなゲームを考えてみましょう。

\
•Game(secrets•[''] points•#)

state: Game(['ねこ' 'いぬ'] 0) … state.secrets.has(Chat()) … state.points: state.points + 1

Stage(
    state.points = state.secrets.length() ? 
        [ Phrase("あなたの勝ち！")]
        [ Group(Stack() [ Phrase("わたしの秘密の言葉を当ててみて") Phrase(`\state.secrets.length() - state.points\ 個の秘密`)])]
)
\

 順番に見ていきましょう。

・1行目、 \•ゲーム(秘密•[''] ポイント•#)\ はこう言っています。 / 秘密の言葉のリストと得点を保存する、 \Game\ というデータ構造を作ります /。 \['']\ は / 任意の数の単語のリスト /。もし決まった長さのリストがほしいなら、それぞれの場所に型の名前をつけられます。 \[# '']\ は、数と単語という2つのものからなるリストです。
・2行目はこう言っています。 / ゲームの状態は、秘密の言葉のリストと0点から始まります。 \チャット\ が変わるたびに、入力された単語が秘密の言葉のリストに入っていれば、得点を1増やした新しいゲーム状態を作ります。/ を組み合わせて作れます。
・プログラムが再評価されるたびに(つまり \チャット\ が変わるたびに)ステージを表示します。得点の数が秘密の言葉の数と同じなら、勝利のステージを表示します。そうでなければ、入力を促す表示と、残りの秘密の言葉の数を表示します。

この例にはいくつか問題があります。

・もし同じ秘密の言葉を何度も当てたら、その分だけ点が増えてしまいます!それぞれの単語を2回までしか数えないように、何を当てたかも覚えておく必要があるかもしれません。
・プレイヤーが複数の単語を入力したら、それは数えるべきでしょうか?

もっと工夫されたゲームの状態と更新の仕組みがあれば、こうした場合にも対応できるでしょう。
