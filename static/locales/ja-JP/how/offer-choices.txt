選択可能な選択肢を表示

画面上にたくさんの選択肢を表示し、視聴者が選んだものに応じて何かを行いたい場合があります。そのためには、次の2つの要素が必要です。

• 選択できる印がついていて、固有の @Phrase を1つ以上持つ \Phrase('オプション1' 選択可能: ⊤ 名前: '1つ')\（例：
• @Choice） @Phrase は、直前に選ばれた

たとえば、ここではそれぞれ一意の名前を持つ 3 つの選択肢を示します。

\
option: Choice()

Group(
	Stack() [
		Phrase('オプション1' 選択可能: ⊤ 名前: '1つ')
		Phrase('オプション2' 選択可能: ⊤ 名前: '二')
		Phrase('オプション3' 選択可能: ⊤ 名前: '三つ')
		Phrase(option)
	]
)
\

 毎回選ばれるたびに最後に @Phrase 選択した名前が表示されます。

このパターンを使えば、選択に応じて何かを実行できます。例えば、上記のプロジェクトを変更して、選択内容に応じて秘密の絵文字を表示するようにすることができます。

\
option: Choice()

option = '' ?
	Group(
		Stack() [
			Phrase('オプション1' 選択可能: ⊤ 名前: '1つ')
			Phrase('オプション2' 選択可能: ⊤ 名前: '二')
			Phrase('オプション3' 選択可能: ⊤ 名前: '三つ')
		]
	)
	Phrase(
		{
			'1つ': '😡'
			'二': '🏀'
			'三つ': '❤'
		}{option} ?? '？'
	)
\

 この @Choice は空の @Text として始まります。だから、プロジェクトが始まるとき、それを確認して、3つの選択肢を表示します。
選択が行われると、それは3つの @Phrase 名前のうちの1つになります。

名前のうちの1つになります。 @Map 選んだものに応じて絵文字を表示するには、
を使って名前を秘密の絵文字に変換できます。 @Map から値を取得するとき、 \ø\ 一致するものがなければ、 \??\ という結果になります。だから \'？'\ を使って、その選択肢がマップにない場合は 
を初期値にします。
