ステージ全体を、古い映画やテレビ、水の中のように見せよう

映画では、場面の見た目を変えることができます。回想シーンはやわらかく明るくなり、古いニュース映像はキズだらけの灰色になります。テレビは砂嵐でザーザーと鳴り、水の中のものはゆらゆらゆれて青くなります。
同じことを、次のものにこれを渡すとできます： @Stage これは次のリストです： @Effect。

これは水の中から見た場面です。

\
ステージ(
	[フレーズ('🐠') フレーズ('🌿' 位置: 位置(1m -1m))]
	エフェクト: [波(0.15m) 色づけ(色(55% 45 220°) 70%) もや(40% 色(70% 30 200°))]
)
\

 それぞれのエフェクトは1つのことだけをします。 @Wave は波のようにゆらし、 @Tint はすべてを1つの色にそめ、 @Haze は流れるきりをその上にかぶせます。
3つ合わせると水のように見えます。エフェクトはリストに書いた順番で使われます。だから、あとのエフェクトは、前のエフェクトの結果を変えます。

組み合わせられるエフェクトは10個あります： @Blur、 @Grade、 @Tint、 @Haze、 @Grain、 @Scanlines、 @Wave、 @Damage、 @Flicker、そして @Vignette。
これは古い映画です： @Grade は色をなくし、次に @Damage、 @Grain、そして @Flicker が古くいたんで、ふらふらした感じにします。

\
ステージ(
	[フレーズ('THE END')]
	エフェクト: [色調補正(コントラスト: 130% あざやかさ: 0%) 傷み(70% 50%) 粒子(25%) ちらつき(15% 2) 周辺減光(60%)]
)
\

 こちらは、電波が弱くなっていくテレビです。

\
ステージ(
	[フレーズ('channel 3')]
	エフェクト: [走査線(40% 速さ: 1) 粒子(50% サイズ: 2) ちらつき(20%)]
)
\

 同じ見た目を何度も使うには、エフェクトのリストを返す関数を作りましょう。
関数の入力が、その見た目の設定になります。この見た目は、深くなるほどにごっていきます。

\
ƒ underwater(depth•%) [
	波(0.2m · depth)
	色づけ(色(55% 45 220°) depth)
	ぼかし(0.03m · depth)
]

ステージ([フレーズ('🐠')] エフェクト: underwater(80%))
\

 見た目は、ゲームの状態で変えることもできます。
ここでは、プレイヤーの残りのライフが1つだけのとき、ステージのはしがぼやけて暗くなります。ライフが増えると、また元にもどります。

\
lives: 3 … ∆ キー() … lives - 1

ステージ(
	[フレーズ(lives → '')]
	エフェクト: lives < 2 ? [ぼかし(0.05m) 周辺減光(70% 色(30% 80 30°))] []
)
\

 エフェクトはステージの中身をおおいますが、これにはかかりません： @Stage.overlay。だから、スコアやボタンは、はっきり読めるままです。

地震のようにステージ全体をゆらすのは、エフェクトではありません。次のものを使います： @Stage は、ほかの出力と同じように動かせます。だから、次のものをつけてあげましょう: @Sequence。

\
ステージ([フレーズ('🏠')] 静止: つなぎ.ぶるぶる(0.5s 回数: 4x))
\

 効果の中には、すばやく動くものがあります。使う人が装置に「動きを減らす」と設定しているときは、すべての効果が止まったままになります。
@Flicker は、どんなに速くと指定しても、1秒に数回より速くはきらめきません。速い点滅は人を傷つけることがあるからです。
