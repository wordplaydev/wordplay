値に基づいて異なるものを表示する

もしあなたが @Phrase スコアやキー操作など、何かに応じて変化する？

条件式の \?\ を使って、2つのうちどちらかを選べます。
条件を書いて、その次に \?\ を書きます。そのあとに、条件が true のときに使う値、次に条件が false のときに使う値を書きます。

スペースキーを押すたびに笑顔が悲しそうな顔に変わり、また元に戻る、そんな笑顔の絵文字です。

\
happy: ⊤ … ∆ Key(' ') … ~happy
Phrase(happy ? '😊' '😢')
\

 この @Reaction は \happy\ として \⊤\ （true）から始まり、スペースキーが押されるたびに \~\ で切り替わります。
次に条件式 \?\ が正しい顔を選びます。

条件式を連結することで、2つ以上の選択肢から選ぶことができます。

\
score: 0 … ∆ Key('1') … score + 1
Phrase(score < 3 ? '🥚' score < 6 ? '🐣' '🐥')
\

 プレス \a\ 数回繰り返して、卵からヒナが孵化する様子を見てください！
