キャラクターを移動可能にする

時には、 @Phrase キーボード、マウス、または指で移動できます。

これをやれば、組み合わせることができます @Phrase と @Placement：

\
Stage(
	[Phrase('感動させる' 位置: Placement())]
	位置: Place(0m 0m -10m)
)
\

 キーボードの矢印キーを使用するか、 @Stage 更新します @Placement、原因は @Phrase その方向へ進む。

でも、知っていましたか？ @Placement は、 / 何にでも / 使えます。 @Place を受け取るものなら、 
何でも使えます。たとえば @Stage には、 @Place があり、カメラがどこを向いているかを決めます。
では、 @Placement として使い、 @Stage の場所を設定して、どうなるか見てみましょう。

\
Stage(
  [
	Phrase('🐈' 位置: Place(-2m 2m))
	Phrase('🐈' 位置: Place(2m -2m))
	Phrase('🐈' 位置: Place(-1m 3m))
  ]
  位置: Placement(Place(0m 0m -10m))
)
\

 これでカメラが動きます！（注： @Placement と \z\ の価値 \10m\ カメラがあらゆるものから遠ざかるようにします。
