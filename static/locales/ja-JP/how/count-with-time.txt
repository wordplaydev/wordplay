時間が経つにつれて数え上げていく

多くのプロジェクトには、時間とともに増えていくものが必要です。タイマー、得点、カウントダウンなどです。
カウンターは、 @Time ストリームと @Reaction を組み合わせて作れます。

また、 @Reaction には3つの部分があります。開始する値、見張るもの、そしてそれが変わったときの新しい値です。
ここでは \0\ から始めて、 @Time を見張り、時計が時を刻むたびに1を足します。

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 毎秒、 @Time が発生し、 @Reaction が \∆ Time(1000ms)\ で気づき、 \count\ が \count + 1\ になります。
この \→ ''\ の最後にある変換で、数を文章に変えるので @Phrase がそれを表示できます。

時間だけでなく、任意の入力を使用できます。このカウンターは、Button() が押された回数をカウントします。

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 毎回 @Button ストリームはクリックまたはタップで変更され、カウントが1つ増加します。

track-points, pick-from-a-list
