文字ひとつひとつに、べつべつの色をつける

1つの @Phrase は、それぞれの字形に、ちがう @Pose を、次の方法で指定できます: @Phrase/poses。
最初の字形には最初のポーズ、2番目の字形には2番目のポーズがつきます。ポーズがなくなったら、また最初にもどります。

3つの色が順番にくり返される、パーティー用のテキストです:

\
フレーズ(
	'party time!'
	顔: 'Luckiest Guy'
	ポーズ: [
		ポーズ(色: 色(25% 70 250°))
		ポーズ(色: 色(50% 80 300°))
		ポーズ(色: 色(58% 90 60°))
	]
)
\

 スペースも字形として数えるので、単語をまたいでも、色は順番にくり返されます。
これらの色は、色合いだけでなく明るさもちがいます。だから、色の見え方がちがう人でも、見分けられます。

ポーズでできることは、色だけではありません。それぞれの字形は、自分の中心を軸にして、かたむいたり、大きくなったり、うすくなったり、動いたりします。だから、文字をはずませることもできます:

\
フレーズ(
	'bounce'
	顔: 'Luckiest Guy'
	ポーズ: [
		ポーズ(色: 色(25% 70 250°) 回転: -10° ずれ: 位置(0m 0.1m))
		ポーズ(色: 色(58% 90 60°) 回転: 10° 不透明度: 0.6)
	]
)
\

 ポーズは、書式つきのテキストでも使えます。ほかの入力と同じように、ほかの値によって変えることもできます。
この脅迫状は、0.25秒ごとに新しいかたむきを選びます:

\
tilt: 0° … ∆ 時間(250ms) … ランダム(-15° 15°)
フレーズ(
	`*ransom* /note/`
	顔: 'Courier Prime'
	ポーズ: [
		ポーズ(回転: tilt ずれ: 位置(0m 0.05m))
		ポーズ(回転: -tilt 大きさ: 1.2)
		ポーズ(回転: tilt ÷ 2 ずれ: 位置(0m -0.05m))
	]
)
\
