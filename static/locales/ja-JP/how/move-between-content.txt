矢印キーでコンテンツを移動する

スライドショーのように、コンテンツを1つずつ順番に見せたいことがあります。矢印キーで前に進んだり /、/ 後ろに戻ったりできます。

このパターンには、どのバージョンにも同じ3つの部分があります。

• @List の、表示したい内容
• @Key ストリーム。キーが押されるたびに変化する
• @Reaction 今どの内容にいるかを覚えているもの

これは一番小さいバージョンです。まずステージをクリックして操作を受け付けるようにしてから、左右の矢印キーを押してください。

\
slides: ['1つめ' '2つめ' '3つめ']

key: Key()

index•#: 1 … ∆ key …
	(key = '右矢印キー') ? ((index < slides.length()) ? index + 1 index)
		(key = '左矢印キー') ? ((index > 1) ? index - 1 index)
			index

Phrase(slides[index])
\

 この @Reaction は、この仕組みの中心です。まずは \1\ から始まり、 @Key が変わるたびに、新しい数を決めます。
右矢印キーが押されたら1を足し、左矢印キーが押されたら1を引き、それ以外はそのままにします。

追加の \?\ のチェックは、数字がリストの端を超えないようにするためのものです。
これがないと端を越えてしまい、表示するスライドがなくなってしまいます。
最後のスライドから最初のスライドに戻るようにしたい場合は、そうすることもできます。

注意：矢印キーの名前は \'左矢印キー'\、 \'右矢印キー'\、 \'ArrowUp'\ でそれに気づき、 \'ArrowDown'\ を組み合わせて作れます。
次のように書くこともできます： \'Left'\ と \'Right'\。キーの名前は自分の言語でも使えます。

注目してほしいのは、 \index\ が数字だけだということです。だから、これは / どんな / 種類の内容にも使えます。文章だけではありません。
この @List を @Group や場面全体のリストに入れ替えても、他のパターンはまったく変わりません：

\
slides: [
	Phrase('三つの部分からなる物語' 大きさ: 3m)
	Group(Stack() [Phrase('🐈') Phrase('猫があらわれる')])
	Phrase('おわり 🎉')
]

key: Key()

index•#: 1 … ∆ key …
	(key = '右矢印キー') ? ((index < slides.length()) ? index + 1 index)
		(key = '左矢印キー') ? ((index > 1) ? index - 1 index)
			index

slides[index]
\

 また、 @Scene もこれと同じことができ、数える手間も少なくて済みます。
次のように渡します： @Scene/pause ので、これは自分では動きません。そして @Scene/step を使って、コマを一方向にひとつ動かします：

\
key: Key()
Scene([
		Phrase('三つの部分からなる物語' 大きさ: 3m)
		Group(Stack() [Phrase('🐈') Phrase('猫があらわれる')])
		Phrase('おわり 🎉')
	] 一時停止 ステップ: ∆ key ? ((key = '左矢印キー') ? -1 (key = '右矢印キー') ? 1 ø) ø)
\

 ここでは \?\ のチェックを書く必要はありません。なぜなら @Scene が自分で両端で止まってくれるので、どのコマを表示しているかを覚えておく必要がないからです。
次のように聞いてみましょう @Spotlight と言いたいなら / 10個中3個目 / をステージに表示します。

注：ギャラリーの中にある、まるごとひとつのプロジェクトでこれを見てみましょう： < スライドショー @https://wordplay.dev/project/example-SlideShow?play>

 この @Reaction 上の方法は、扱うものが出力ではないときにも使えます。たとえば、言葉や色、数字のリストなど、何かを作るための材料を1つずつ扱うときです。
