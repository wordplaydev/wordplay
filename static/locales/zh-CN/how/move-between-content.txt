用方向键在内容间移动

有时候，你想让观众一次翻一页内容，像放幻灯片一样，用方向键向前 / 和 / 向后翻。

这种模式的每个版本都由相同的三部分组成：

• 一个 @List ，装着你想显示的内容
• 一个 @Key 流，每次按下一个键都会变化
• 一个 @Reaction ，用来记住你现在停在哪一份内容上

下面是它最简单的版本。先点一下舞台，让它能“听到”按键，然后按左右方向键试试吧：

\
slides: ['第一' '第二' '第三']

key: Key()

index•#: 1 … ∆ key …
	(key = 'ArrowRight') ? ((index < slides.length()) ? index + 1 index)
		(key = 'ArrowLeft') ? ((index > 1) ? index - 1 index)
			index

Phrase(slides[index])
\

 这个 @Reaction 是整个机制的核心。它从 \1\ 开始，每次 @Key 变化时，它都会决定新的数字应该是多少。
如果按下的是右箭头键，就加一；如果按下的是左箭头键，就减一；否则数字保持不变。

额外的 \?\ 检查，就是用来防止数字超出列表两端的。
没有这些检查，你就可能走到列表末尾之外，导致没有幻灯片可以显示。
如果你更想让它从最后一张幻灯片绕回第一张，那也是可以做到的。

注意：方向键的名字是 \'ArrowLeft'\、 \'ArrowRight'\、 \'ArrowUp'\ 注意到，然后 \'ArrowDown'\ 结合起来，做一个计数器。
你也可以直接写 \'Left'\ 和 \'Right'\，而且键名也可以用你自己的语言来写。

注意 \index\ 只是一个数字，所以这个方法对 / 任何 / 类型的内容都适用，不只是文本。
把 @List 换成一份 @Group 的列表，或者整段场景，其余的写法完全不用变：

\
slides: [
	Phrase('一个分三部分的故事' 尺寸: 3m)
	Group(Stack() [Phrase('🐈') Phrase('一只猫出现了')])
	Phrase('结束了🎉')
]

key: Key()

index•#: 1 … ∆ key …
	(key = 'ArrowRight') ? ((index < slides.length()) ? index + 1 index)
		(key = 'ArrowLeft') ? ((index > 1) ? index - 1 index)
			index

slides[index]
\

 一个 @Scene 也能做到这一点，而且用到的计数更少。
给它 @Scene/pause 所以它自己不会移动，而 @Scene/step 用来把它移动一格：

\
key: Key()
Scene([
		Phrase('一个分三部分的故事' 尺寸: 3m)
		Group(Stack() [Phrase('🐈') Phrase('一只猫出现了')])
		Phrase('结束了🎉')
	] 暂停 步进: ∆ key ? ((key = 'ArrowLeft') ? -1 (key = 'ArrowRight') ? 1 ø) ø)
\

 这里不需要写任何 \?\ 检查，因为 @Scene 会自动在两端停住，不需要记住当前显示的是哪一个。
问问 @Spotlight ，如果你想说 / 第 3 个，共 10 个 / 在舞台上。

注：可以在作品库里看到一个完整的项目： < 幻灯片 @https://wordplay.dev/project/example-SlideShow?play>

 这个 @Reaction 仍然是一种做法，适用于你要一步步处理的东西不是输出的情况——比如一份文字、颜色或数字的列表，或者任何你用来搭建作品的材料。
