显示可选的选项

有时你想在屏幕上显示一系列选项，并根据观众的选择执行相应的操作。为此，我们需要做两件事：

• 一个或多个 @Phrase 标记为可选，并具有唯一名称（例如， \Phrase('选项 1' 可选择的: ⊤ 名字: '一')\）
• 一个 @Choice，这会变成 @Phrase 最近选择的名称。

举个例子，这里我们显示三个选项，每个选项都有一个唯一的名称。

\
option: Choice()

Group(
	Stack() [
		Phrase('选项 1' 可选择的: ⊤ 名字: '一')
		Phrase('选项 2' 可选择的: ⊤ 名字: '二')
		Phrase('选项 3' 可选择的: ⊤ 名字: '三')
		Phrase(option)
	]
)
\

 每次选择一个，最后 @Phrase 显示所选的名称。

你可以使用这个模式来响应用户选择。例如，我们可以修改上面的项目，让它根据用户选择显示一个秘密表情符号：

\
option: Choice()

option = '' ?
	Group(
		Stack() [
			Phrase('选项 1' 可选择的: ⊤ 名字: '一')
			Phrase('选项 2' 可选择的: ⊤ 名字: '二')
			Phrase('选项 3' 可选择的: ⊤ 名字: '三')
		]
	)
	Phrase(
		{
			'一': '😡'
			'二': '🏀'
			'三': '❤'
		}{option} ?? '？'
	)
\

 这个 @Choice 以空白的 @Text 开始  ，因此当项目开始时，我们会检查这一点，并显示三个选择。
一旦做出选择，它就成为三个 @Phrase 名字之一。

要根据选择显示一个表情符号，我们可以用一个 @Map 把名字换成一个神秘的表情符号。
我们从 @Map 取一个值时，如果没有匹配上，它会求值为 \ø\，所以我们用 \??\ 来设定一个默认值，也就是 \'？'\ ，以防这个选项不在这个映射里。 
在这种情况下，这种事永远不会发生，但我们还不够聪明，没法知道这一点！
