让整个舞台看起来像老电影、电视或水中

电影可以改变整个场景的样子：回忆画面变得柔和明亮，旧新闻片布满划痕、一片灰色，电视屏幕噼啪作响满是雪花，水下的一切则会泛起波纹、变成蓝色。
我们也可以做到，只要给一个 @Stage 一个 @Effect 的列表。

这是透过水看到的场景。

\
舞台(
	[短语('🐠') 短语('🌿' 位置: 位置(1m -1m))]
	效果: [波浪(0.15m) 着色(颜色(55% 45 220°) 70%) 雾气(40% 颜色(70% 30 200°))]
)
\

 每个效果只做一件事。 @Wave 让画面泛起波纹， @Tint 把所有东西染成同一种颜色， @Haze 则在上面铺一层飘动的雾。
合在一起，它们看起来就像水。效果会按列出的顺序依次应用，所以后面的效果会改变前面效果的结果。

一共有十种可以组合： @Blur、 @Grade、 @Tint、 @Haze、 @Grain、 @Scanlines、 @Wave、 @Damage、 @Flicker，还有 @Vignette 的列表。
这是一部老电影： @Grade 先去掉颜色，然后 @Damage、 @Grain，还有 @Flicker 让画面变得陈旧、抖动不稳。

\
舞台(
	[短语('THE END')]
	效果: [调色(对比度: 130% 饱和度: 0%) 损坏(70% 50%) 颗粒(25%) 闪动(15% 2) 暗角(60%)]
)
\

 这是一台信号丢失的电视。

\
舞台(
	[短语('channel 3')]
	效果: [扫描线(40% 速度: 1) 颗粒(50% 大小: 2) 闪动(20%)]
)
\

 如果想反复使用同一种外观，可以写一个函数，让它返回这些效果的列表。
函数的输入就成了这种外观自己的设置。这个外观会越往深处越模糊。

\
ƒ underwater(depth•%) [
	波浪(0.2m · depth)
	着色(颜色(55% 45 220°) depth)
	模糊(0.03m · depth)
]

舞台([短语('🐠')] 效果: underwater(80%))
\

 外观也可以随着游戏的状态而变化。
在这里，当玩家只剩一条命时，舞台边缘会变模糊、变暗；生命多的时候，就会重新变清晰。

\
lives: 3 … ∆ 按键() … lives - 1

舞台(
	[短语(lives → '')]
	效果: lives < 2 ? [模糊(0.05m) 暗角(70% 颜色(30% 80 30°))] []
)
\

 效果会盖住舞台上的内容，但不会盖住舞台的 @Stage.overlay，所以分数或按钮依然清晰易读。

像地震一样晃动整个舞台，根本不是效果： @Stage 可以像其他输出一样移动，所以给它一个 @Sequence 的列表。

\
舞台([短语('🏠')] 休息时: 序列.抖动(0.5s 计数: 4x))
\

 有些效果动得很快。如果有人已经让设备减少动态效果，所有效果都会保持不动。
@Flicker 每秒闪烁的次数不会太多，无论你要求多快，因为快速闪烁会伤害到人。
