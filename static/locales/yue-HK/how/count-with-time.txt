隨住時間過去不斷數數

好多專案都需要一啲會隨時間增加嘅嘢，例如計時器、分數或者倒數。
我哋可以結合呢個 @Time 串流同一個 @Reaction。

一個 @Reaction 有三個部分：一個起始值、一樣要監察嘅嘢，同埋嗰樣嘢有變化時嘅新值。
喺呢度，我哋由 \0\ 開始，監察 @Time，每次時鐘跳一下就加一：

\
數量2: 0 … ∆ 時間(1000ms) … 數量2 + 1
短語(數量2 → '')
\

 每一秒， @Time 都會觸發， @Reaction 會留意到，用 \∆ 時間(1000ms)\ 同 \count\ 就會變成 \count + 1\。
呢個 \→ ''\ 最尾嗰個會將數字轉成文字，咁 @Phrase 就可以顯示出嚟。

你可以用任何輸入，唔止時間。呢個計數器會數 Button() 被撳咗幾多次：

\
數量2: 0 … ∆ 按鈕() … 數量2 + 1
短語(數量2 → '')
\

 每次 @Button 串流因為點擊或者輕觸而改變，計數就會加一。
