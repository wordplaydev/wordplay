記錄分數

玩遊戲嗰時，有事發生就記低分數，好有用。如果 @wordplay 唔畀變數改成新嘅值，我哋點樣做到呢？

竅門係用一個 @Reaction 嚟定義一個 @Bind 嘅值，仲要諗清楚咩事件發生先會畀呢個 @Bind。

例如，想像一個好簡單嘅遊戲：玩家每次喺鍵盤㩒一粒秘密鍵，就會多啲分數。 

\
點2: 0 … ['a' 'e' 'i' 'o' 'u'].包含(鍵()) … 點2 + 1
\

 呢個例子係話： / 分數由 0 開始，之後每次有鍵被㩒，如果個鍵喺母音清單入面，分數就變成而家嘅分數加一。/ 每次 \鍵()\ 串流有變，程式就會重新計算，檢查條件，如果條件係真，就畀 \points\ 一個新嘅值。

呢個反應有三個部分：

• 分數嘅起始值（\0\）
• 條件，條件為真嘅時候會產生新嘅值（\['a' 'e' 'i' 'o' 'u'].包含(鍵())\）
• 新嘅值，喺條件變成真嘅時候用（\points + 1\）

想做更複雜嘅分數記錄，只要寫更複雜嘅條件或者新嘅值就得。花啲時間諗清楚呢啲條件同新值嘅規則，然後試吓用程式碼寫出嚟。
