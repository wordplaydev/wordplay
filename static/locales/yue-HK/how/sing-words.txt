等把聲唱出文字

喺調色盤入面嘅每一個 @Instrument 當中， \樂器.人聲\ 係唯一識講嘢嘅。畀佢 @Track 」一個「 @Track/words 佢就會一個音節一個音符噉唱出嚟：

\
音樂(
	音軌([1 2 3 5 3 1] 字詞: '啦 啦 啦 啦 啦 啦' 樂器: 樂器.人聲)
	速度: 120beats/min
)
\

 六個音節，六個音符。空格就係成套文法，佢話畀你知一個音節喺邊度完、下一個喺邊度開始。休止符唔使音節，所以啲字會落喺你真正聽到嘅音符上面。如果音節少過音符，佢哋會由頭再嚟；如果一個都冇寫，聲音就會唱住一個 / uh / 音，所以佢總會唱啲嘢。

呢度嘅拼法唔係英文拼法，而係 < 國際音標 @https://en.wikipedia.org/wiki/International_Phonetic_Alphabet>。喺國際音標入面，每個字母剛好係一個聲音，每個聲音又剛好有一個字母。英文拼法做唔到，因為 \o\ 喺 / 去 /、 / do / 同 / women / 入面係三個唔同嘅聲音，所以如果聲音照英文拼法嚟讀，就要估，仲會估錯。咁亦都表示，無論你用邊種語言寫，歌詞都一樣用得，因為啲字母描述嘅係你把口點樣發音，而唔係你嘅字母表。

你個鍵盤上面冇鍵可以打到大部分呢啲音，所以㩒編輯器下面嘅 🤖。佢會列出聲音可以發出嘅所有音，每個音都有一個包含佢嘅字同一個可以播放佢嘅按鈕，㩒個字母本身就會將佢打入你嘅程式碼。聽到個音先至真正識佢，而個面板就係參考資料；下面嘅內容已經夠你起步。

由元音開始。呢十二個已經涵蓋你大部分時間想用嘅音，每個都放喺一個有佢嘅英文字入面：

\a\ f / a / ther, \e\ b / e / d, \i\ s / ee /、 \o\ g / o /、 \u\ b / oo / t， \ɛ\ h / ea / d, \ɪ\ b / i / t， \ɔ\ b / ou / ght， \ʊ\ b / oo / k， \æ\ c / a / t， \ʌ\ c / u / p， \ə\ / a / bout

單一個元音已經可以係一個完整嘅音節。將佢哋逐個連續唱出嚟，係最清楚分辨每個元音嘅方法：

\
音樂(
	音軌([1 2 3 4 5] 字詞: '啊 咿 唔 喔 嗚' 樂器: 樂器.人聲)
	速度: 90beats/min
)
\

 大部分輔音睇落同你預期嘅差唔多： \p b t d k m n s f l r w\ 嘅讀音同英文差唔多。值得學嘅，係英文用兩個字母拼出嚟嘅音，仲有一個轉咗位置嘅字母。 \ʃ\ 係 / sh /、 \ʒ\ 係 / s / 喺 / 量度 /、 \θ\ 係 / th / 喺 / 薄 /、 \ð\ 係 / th / 喺 / 呢個 /、 \ŋ\ 係 / ng / 喺 / 唱歌 / 同 \j\ 係 / y / 喺 / 係 /。將其中一個放喺元音前面，就成為一個字喇：

\
音樂(
	音軌([5 5 3 3 1] 字詞: '嘘 絲 咪 囉 啪' 樂器: 樂器.人聲)
	速度: 100beats/min
)
\

 一個音節都可以拖過幾個音符。喺音節尾加連字號，每個連字號就令佢多撐一個音符。同一個音節行過一串音符，令聖詩同搖籃曲有佢哋嘅旋律形狀：

\
音樂(
	音軌([1 2 3 2 1] 字詞: '榮---耀' 樂器: 樂器.人聲)
	速度: 140beats/min
)
\

 三個連字號令 \glo\ 延伸過四個音符，然後 \ri\ 落喺最後一個音符上面。聲音唔認得嘅嘢，佢會跳過而唔係拒絕，所以你可以放心試，唔會整壞首曲。

想顯示唱緊嘅歌詞，就由 @Beat 讀返出嚟。 @Downbeat/words 會帶住嗰一刻正喺度唱緊嘅嘢，所以一個詞組就可以成個卡拉 OK 畫面：“},{

\
節拍: 拍子()
舞台([
	短語(((節拍.字詞.長度() = 0) ? '' 節拍.字詞[1]) 3m)
	音樂(
		音軌([1 2 3 5 3 1] 字詞: '呢 首 係 一 首 歌 嚟 睇' 樂器: 樂器.人聲)
		速度: 100beats/min
	)
])
\
