記住遊戲狀態

大部分遊戲喺玩嘅時候，都要記住好多嘢：分數、玩家嘅位置，同其他細節都好重要。
每次有輸入，狀態就會變，然後我哋就要顯示新嘅輸出作為回應。

所有遊戲通用嘅做法，有三個步驟：

• 定義一個遊戲狀態嘅資料結構，用嚟儲存所有遊戲狀態
• 定義一個反應：每次有新輸入，就根據之前嘅遊戲狀態，整一個新嘅遊戲狀態
• 整一個 @Stage 配 @Group 同 @Phrase 嚟顯示遊戲狀態

例如，諗下一個簡單嘅遊戲：喺文字框入面打秘密字，每估中一個秘密字就得一分：

\
•Game(secrets•[''] points•#)

state: Game(['cat' 'dog'] 0) … state.secrets.包含(傾偈()) … state.points: state.points + 1

舞台(
    state.points = state.secrets.長度() ? 
        [ 短語("you win!")]
        [ 組合(堆疊() [ 短語("guess my secret words") 短語(`\state.secrets.length() - state.points\ more secrets`)])]
)
\

 等我哋逐步拆開嚟睇。

• 第一行， \•遊戲(秘密•[''] 點2•#)\ 意思係， / 整一個資料結構，名叫 \Game\ ，用嚟儲存一個秘密列表同分數 /。個 \['']\ 嘅意思係 / 係指一個有任何數量文字嘅列表 /。如果你想要一個長度固定嘅列表，可以為列表入面每個位置指定一個類型： \[# '']\ 係一個有兩樣嘢嘅列表，先係一個數字，再係一個字。
• 第二行嘅意思係 / 遊戲狀態一開始有一個秘密列表同零分。每次個 \傾偈\ 改變，如果輸入嘅字喺秘密列表入面，就整一個新嘅遊戲狀態，分數加一 /。
• 每次程式重新運算（當個 \傾偈\ 改變嘅時候），就顯示一個舞台。如果分數等於秘密嘅數量，就顯示勝利舞台。如果唔係，就顯示一個提示，同剩低幾多個秘密。

呢個例子有啲問題：

• 如果佢哋估中同一個秘密字好多次，就會得到更多分數！我哋嘅遊戲狀態可能仲要記住估過啲咩字，咁每個字就只會計一次。
• 如果玩家輸入多過一個字，算唔算㗎？

如果有更完善嘅遊戲狀態同遊戲更新，就可以幫我哋處理呢啲情況。
