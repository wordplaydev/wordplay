顯示可以揀嘅選項

有時你想喺螢幕上面顯示一堆選項，再根據觀眾揀咗乜嚟做嘢。要做到呢樣，我哋需要兩樣嘢：

• 一個或者多個 @Phrase ，要標記為可以揀，同埋有一個獨一無二嘅名稱（例如： \短語('選項 1' 可選取 名稱: '一個')\）
• 一個 @Choice，佢會變成最近揀咗嘅 @Phrase 名稱。

例如，呢度我哋顯示三個選項，每個都有獨一無二嘅名稱。

\
選項: 選擇()

組合(
	堆疊() [
		短語('選項 1' 可選取 名稱: '一個')
		短語('選項 2' 可選取 名稱: '兩個')
		短語('選項 3' 可選取 名稱: '三')
		短語(選項)
	]
)
\

 每次揀咗一個，最後嘅 @Phrase 就會顯示所揀嘅名稱。

你可以用呢個做法，喺有人揀咗之後做啲反應。例如，我哋可以改一改上面嘅專案，根據所揀嘅選項顯示一個秘密表情符號：

\
選項: 選擇()

選項 = '' ?
	組合(
		堆疊() [
			短語('選項 1' 可選取: ⊤ 名稱: 'one')
			短語('選項 2' 可選取: ⊤ 名稱: 'two')
			短語('選項 3' 可選取: ⊤ 名稱: 'three')
		]
	)
	短語(
		{
			'one': '😡'
			'two': '🏀'
			'three': '❤'
		}{選項} ?? '?'
	)
\

 呢個 @Choice 一開始係一個空嘅 @Text，所以專案開始嗰陣，我哋檢查呢樣，然後顯示三個選項。
一旦揀咗，佢就會變成三個 @Phrase 名稱其中一個。

想根據所揀嘅選項顯示表情符號，我哋可以用一個 @Map ，將名稱轉換成秘密表情符號。
當我哋從一個 @Map 攞值嗰陣，如果冇配對到，結果就係 \ø\，所以我哋用 \??\ 喺選項唔喺對應表入面嗰陣，預設為 \'?'\ 。 
喺呢個情況，呢樣嘢永遠都唔會發生，不過我哋冇咁聰明，知唔到呢點！
