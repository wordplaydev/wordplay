畀每個字母自己嘅顏色

一個 @Phrase 可以畀佢每個字形都有唔同嘅 @Pose 配 @Phrase/poses。
第一個字形用第一個姿勢，第二個字形用第二個姿勢。姿勢用晒之後，就由第一個重新開始。

呢度有段派對文字，三種顏色輪流出現：

\
短語(
	'派對時間！'
	字體: 'Luckiest Guy'
	姿勢: [
		姿勢(顏色: 顏色(25% 70 250°))
		姿勢(顏色: 顏色(50% 80 300°))
		姿勢(顏色: 顏色(58% 90 60°))
	]
)
\

 空格都算係字形，所以顏色會跨過一個個字繼續輪流出現。
呢啲顏色嘅明暗同色相都唔同，所以睇到顏色有分別嘅人都可以分得出佢哋。

姿勢唔止可以轉顏色。每個字形都可以傾斜、放大、變淡，仲可以圍住自己嘅中心移動，所以我哋可以整到啲字母彈嚟彈去：

\
短語(
	'彈跳'
	字體: 'Luckiest Guy'
	姿勢: [
		姿勢(顏色: 顏色(25% 70 250°) 旋轉: -10° 偏移: 地點(0m 0.1m))
		姿勢(顏色: 顏色(58% 90 60°) 旋轉: 10° 透明度: 0.6)
	]
)
\

 姿勢同有格式嘅文字一樣用得，而且同其他輸入一樣，可以跟住其他值而變。
呢張勒索信每四分之一秒就揀一個新嘅傾斜角度：

\
傾斜: 0° … ∆ 時間(250ms) … 隨機(-15° 15°)
短語(
	`*勒索* /信/`
	字體: 'Courier Prime'
	姿勢: [
		姿勢(旋轉: 傾斜 偏移: 地點(0m 0.05m))
		姿勢(旋轉: -傾斜 音階: 1.2)
		姿勢(旋轉: 傾斜 ÷ 2 偏移: 地點(0m -0.05m))
	]
)
\
