整一組有動畫嘅場景

有時我哋想講故事、顯示歌詞，或者畀詩句郁起上嚟。
要咁做，我哋可以一齊用 @Scene 同 @Phrase ，嚟顯示一連串嘅內容。

例如，想像我哋想畀短短嘅兒歌「Jack be Nimble」郁起上嚟。
我哋可以整一個 @Scene ，將每一句都放喺一個 @Phrase 入面，再設定每一句嘅 @Phrase/duration ，到每句做完， @Scene 就會跳去下一句。

\
場景([
  短語('傑克要靈活' 時長: 1s)
  短語('傑克要夠快' 時長: 1s)
  短語('傑克跳過燭台' 時長: 1s)
])
\

@Scene 都會等一個 @Sequence 做完。等我哋畀蠟燭嗰句跳起上嚟啦！

\
場景([
		短語('傑克要靈活' 時長: 1s)
		短語('傑克要夠快' 時長: 1s)
		短語('傑克跳過燭台' 進場: 序列.彈跳(時長: 1s))
	])
\

@Scene 都可以放一個文字嘅 @Group ，而且佢會等晒入面所有內容做完動畫。

\
場景([
		組合(堆疊() [
      短語('傑克要靈活')
		  短語('傑克要夠快')
    ] 時長: 2s)
		短語('傑克跳過燭台' 進場: 序列.彈跳(時長: 1s))
	])
\

 有時兒歌要一直重複。 @Scene/loop 會將 @Scene 轉返去第一個 @Phrase ，等最後一個做完之後，佢就會一次又一次咁重複講。

\
場景([
		短語('傑克要靈活' 時長: 1s)
		短語('傑克要夠快' 時長: 1s)
		短語('傑克跳過燭台' 時長: 1s)
	] 迴圈: ⊤)
\

 注意：一個 @Scene 淨係喺清單入面真係有嘢等過先會轉返頭。
如果清單入面每個 @Phrase 嘅 @Phrase/duration 都係 \0s\ ，就會好似電腦跑得幾快就幾快咁轉，所以到最後佢就會停低。
