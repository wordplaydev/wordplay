設計你嘅文字樣式

有時我哋想文字更突出。我哋可以用呢啲方法： / 斜體 /、 * 粗體 *，仲有更多！

例如，想將文字變成斜體，你可以用斜線 // 包住佢，好似 //Hello// 咁。例如：


\
組合(堆疊() [
        短語(`想喺你嘅文字用吓 /斜體/ 嗎？`)
        短語(`斜體好適合用嚟強調，或者令你啲字更加 /有味道/。`)
        短語(`只要喺個字或者一句說話嘅前後各加一個斜線 (//)，就好似 /咁/。`)
    ]
)
\


@Phrase 都可以將文字變粗。你可以用星號 ** 包住文字，好似 **Hello** 咁。例如：

\
組合(堆疊() [
        短語(`想用 *粗體* 令你嘅文字更突出嗎？`)
        短語(`當你想 *大聲叫出嚟* 嗰陣，用粗體就最啱。`)
        短語(`只要喺你啲字前後各加一個星號 (**)，例如 *喂！*，就即刻睇得出分別。`)
      ]
)
\

@Phrase 都可以將文字變成超粗。呢個做法係用插入號 ^^ 包住文字，好似 ^^Hello^^ 咁。例如：

\
組合(堆疊() [
        短語(`當你想將效果推到最盡，特粗體就最勁 ^無敵^。`)
        短語(`佢好似粗體，不過更加 ^搶眼^，通常喺前後各加一個插入號 (^^)。`)
        短語(`可以用嚟突出 ^標題^ 或者 ^大想法^。`)
    ]
)
\

 最後， @Phrase 都可以畀文字加底線。呢個做法係用底線符號 __ 包住文字，好似 __Hello__ 咁。例如：

\
組合(堆疊() [
        短語(`想文字簡潔但又夠突出，_底線_ 就好好用。`)
        短語(`喺你嘅文字前後各加一個底線符號 (__)，就好似 _咁_，強調得好乾淨。`)
        短語(`想講清楚重點但又唔好太 _誇張_，用底線就 _最啱_。`)
    ]
)
\
