令成個舞台好似舊戲、電視或者水底咁

電影可以改變成個場景嘅感覺：回憶畫面會變得柔和又光猛，舊新聞片會有刮痕同灰灰哋，電視會閃住雪花，而水底嘅嘢就會起波紋兼變藍。
我哋都可以咁做，只要畀一個 @Stage 一個清單，入面有 @Effect。

呢個係隔住水睇嘅場景。

\
舞台(
	[短語('🐠') 短語('🌿' 位置: 地點(1m -1m))]
	效果: [波浪(0.15m) 色調(顏色(55% 45 220°) 70%) 朦朧(40% 顏色(70% 30 200°))]
)
\

 每種效果只做一件事。 @Wave 令畫面起波紋， @Tint 令所有嘢染上同一種顏色，而 @Haze 就喺上面鋪一層飄動嘅霧。
加埋一齊就好似水底咁。效果會跟住清單嘅次序套用，所以後面嘅效果會改變前面效果嘅結果。

一共有十種可以配合使用： @Blur、 @Grade、 @Tint、 @Haze、 @Grain、 @Scanlines、 @Wave、 @Damage、 @Flicker 同 @Vignette。
呢個係一齣舊電影： @Grade 會去除顏色，跟住 @Damage、 @Grain 同 @Flicker 令畫面變得殘舊同晃動。

\
舞台(
	[短語('完')]
	效果: [調色(對比度: 130% 飽和度: 0%) 損壞(70% 50%) 顆粒(25%) 閃爍(15% 2) 暗角(60%)]
)
\

 呢個就係一部收唔到訊號嘅電視。

\
舞台(
	[短語('頻道 3')]
	效果: [掃描線(40% 速度: 1) 顆粒(50% 大小: 2) 閃爍(20%)]
)
\

 如果想重複用同一個效果，可以整一個函數，畀返佢嘅效果清單。
佢嘅輸入就變成呢個效果自己嘅設定。呢個效果越深入就越模糊。

\
ƒ underwater(depth•%) [
	波浪(0.2m · depth)
	色調(顏色(55% 45 220°) depth)
	模糊(0.03m · depth)
]

舞台([短語('🐠')] 效果: underwater(80%))
\

 效果亦都可以跟住遊戲嘅狀態而變。
呢度當玩家淨返一條命嘅時候，舞台邊緣會變模糊同變暗，有多啲命嘅時候就會回復清晰。

\
命數: 3 … ∆ 鍵() … 命數 - 1

舞台(
	[短語(命數 → '')]
	效果: 命數 < 2 ? [模糊(0.05m) 暗角(70% 顏色(30% 80 30°))] []
)
\

 效果會蓋住舞台上面嘅嘢，但係唔會蓋住佢嘅 @Stage.overlay，所以分數或者按鈕都會保持清楚易睇。

搖晃成個舞台，好似地震咁，其實唔係效果嚟㗎：一個 @Stage 可以好似其他輸出咁郁，所以畀佢一個 @Sequence。

\
舞台([短語('🏠')] 靜止: 序列.搖晃(0.5s 次數: 4x))
\

 有啲效果郁得好快。如果有人叫佢部裝置減少動態，所有效果都會停定唔郁。
@Flicker 就算你要求幾快，閃爍速度都唔會超過每秒幾次，因為閃得太快可能會傷害到人。
