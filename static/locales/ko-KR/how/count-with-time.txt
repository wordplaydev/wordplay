시간이 흐르는 동안 카운트다운

많은 프로젝트에는 시간이 지나면서 커지는 무언가가 필요합니다 — 타이머, 점수, 카운트다운 같은 것들이죠.
우리는 @Time 스트림과 @Reaction 을 결합해 카운터를 만들 수 있습니다.

A @Reaction 는 세 부분으로 이루어져 있습니다: 시작 값, 지켜볼 대상, 그리고 그 대상이 바뀔 때의 새 값입니다.
여기서는 \0\ 에서 시작해서, @Time 를 지켜보다가, 시계가 똑딱거릴 때마다 하나씩 더합니다:

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 1초마다 @Time 가 울리면, @Reaction 가 \∆ Time(1000ms)\ 로 이를 알아채고, \count\ 는 \count + 1\ 가 됩니다.
The \→ ''\ 맨 끝에 있는 것은 숫자를 텍스트로 바꿔서 @Phrase 가 보여줄 수 있게 합니다.

시간뿐만 아니라 원하는 입력값을 사용할 수 있습니다. 이 카운터는 Button() 함수가 눌린 횟수를 계산합니다.

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 매번 @Button 스트림이 클릭이나 탭으로 변경되면 카운트가 1씩 증가합니다.

track-points, pick-from-a-list
