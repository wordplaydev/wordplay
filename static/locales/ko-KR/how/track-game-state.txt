게임 상태를 계속 확인하기

대부분의 게임은 게임이 진행되면서 여러 가지를 추적합니다. 점수, 플레이어 위치, 그리고 다른 세부 정보가 모두 중요합니다.입력이 들어올 때마다 그 상태가 바뀌고, 그에 응답해서 새 출력을 보여주고 싶어져.

모든 게임에 쓰이는 일반적인 방식은 세 가지 일을 합니다:

• 게임 상태 자료 구조를 정의해서 모든 게임 상태를 저장하세요• 새 입력이 들어올 때마다 이전 게임 상태를 바탕으로 새로운 게임 상태를 만드는 반응을 정의하자• 만들기  @Stage  와(과)  @Group  및  @Phrase  게임 상태를 보여 주기 위해

예를 들어, 간단한 게임 하나를 상상해 보자. 글상자에 비밀 단어를 입력하고, 비밀 단어를 맞힐 때마다 점수를 얻는 게임이야:

\•Game(secrets•[''] points•#)
state: Game(['고양이' '강아지'] 0) … state.secrets.has(Chat()) … state.points:state.points + 1
Stage(
	state.points = state.secrets.length() ? [
			Phrase("네가 이겼어!")
		] [
			Group(
				Stack()
				[
					Phrase("내 비밀 단어를 맞혀 봐")
					Phrase(
						`\state.secrets.length() - state.points\ 더 많은 비밀`
					)
				]
			)
		]
)\

이걸 하나씩 살펴보자.

• 첫 번째 줄, \•게임(비밀•[''] 점수•#)\ 말하길, /다음 이름의 데이터 구조를 만들어 보자 \Game\ 비밀과 점수 목록을 저장하는/. 그 \[
	''
]\ 뜻은 /단어를 원하는 개수만큼 담은 목록/. 만약 정확한 길이의 목록을 원한다면, 각 자리마다 유형 을 이름 지어 정할 수 있습니다: \[
	#'']\은 숫자 하나와 단어 하나, 이렇게 두 가지로 이루어진 목록입니다.• 두 번째 줄은 이렇게 말합니다: /게임 상태는 비밀 목록과 0점으로 시작합니다. \채팅\이 바뀔 때마다, 입력한 단어가 비밀 목록에 있으면 점수를 1점 늘린 새 게임 상태를 만듭니다/.• 프로그램이 다시 평가될 때마다 (즉 \채팅\이 바뀔 때) 무대를 보여줍니다. 점수 수가 비밀 개수와 같으면 승리 무대를 보여줍니다. 그렇지 않으면 안내문과 남은 비밀 개수를 보여줍니다.

이 예시에는 몇 가지 문제가 있습니다:

• 같은 비밀 단어를 여러 번 맞히면 점수가 계속 늘어납니다! 게임 상태는 어떤 단어를 이미 맞혔는지도 기억해서, 각 단어가 두 번까지만 점수로 계산되게 해야 할 수도 있습니다.• 플레이어가 여러 단어를 한꺼번에 입력하면, 그것도 점수로 계산해야 할까요?
