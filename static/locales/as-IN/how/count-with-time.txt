সময় পাৰ হৈ যোৱাৰ লগে লগে ওপৰলৈ গণনা কৰক

বহুতো প্ৰকল্পৰ এনে কিছুমান বস্তুৰ প্ৰয়োজন হয় যিয়ে সময়ৰ লগে লগে বাঢ়ি যায় — যেনে এটা টাইমাৰ, এটা স্ক'ৰ, বা এটা কাউণ্টডাউন।
আমি @Time সোঁতটোক এটা @Reaction ৰ লগত মিলাই এটা কাউণ্টাৰ বনাব পাৰোঁ।

এটা @Reaction ৰ তিনিটা অংশ আছে: এটা আৰম্ভণিৰ মান, চাবলগীয়া এটা বস্তু, আৰু সেই বস্তুটো সলনি হ'লে এটা নতুন মান।
ইয়াত, আমি \0\ ৰ পৰা আৰম্ভ কৰোঁ, @Time লৈ চাওঁ, আৰু ঘড়ীটোৱে টিক্ কৰাৰ প্ৰতিবাৰতে এটাকৈ যোগ কৰোঁ:

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 প্ৰতি ছেকেণ্ডত, @Time চলে, @Reaction এ \∆ Time(1000ms)\ ৰ সৈতে তাক লক্ষ্য কৰে, আৰু \count\ হৈ যায় \count + 1\ ৰ লগত মিলাই এটা কাউণ্টাৰ বনাব পাৰোঁ।
এই \→ ''\ শেষত থকা @Phrase এ ইয়াক দেখুৱাব পাৰে বাবে সংখ্যাটোক পাঠলৈ ৰূপান্তৰ কৰে।

আপুনি কেৱল সময় নহয়, আপুনি বিচৰা যিকোনো ইনপুট ব্যৱহাৰ কৰিব পাৰে। এই কাউণ্টাৰটোৱে Button() টিপৰ সংখ্যা গণনা কৰে:

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 প্ৰতিবাৰেই... @Button ষ্ট্ৰিম এটা ক্লিক বা টেপৰ সৈতে সলনি হয়, গণনা এটা বৃদ্ধি পায়।
