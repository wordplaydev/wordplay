Afficher les choix sélectionnables

Parfois, on souhaite présenter plusieurs choix à l'écran et exploiter les choix du public. Pour cela, deux éléments sont nécessaires :

• Un ou plusieurs @Phrase marqués comme sélectionnables et ayant un nom unique (par exemple, \Phrase('option 1' sélectionnable: ⊤ nom: 'un')\)
• Une @Choice, qui change pour prendre le nom @Phrase choisi le plus récemment.

Par exemple, nous montrons ici trois choix, chacun avec un nom unique.

\
option: Choice()

Group(
	Stack() [
		Phrase('option 1' sélectionnable: ⊤ nom: 'un')
		Phrase('option 2' sélectionnable: ⊤ nom: 'deux')
		Phrase('option 3' sélectionnable: ⊤ nom: 'trois')
		Phrase(option)
	]
)
\

 Chaque fois qu'on en choisit un, le dernier @Phrase affiche le nom sélectionné.

Vous pouvez utiliser ce modèle pour réagir à un choix. Par exemple, nous pourrions modifier le projet ci-dessus pour afficher un emoji secret basé sur ce choix :

\
option: Choice()

option = '' ?
	Group(
		Stack() [
			Phrase('option 1' sélectionnable: ⊤ nom: 'un')
			Phrase('option 2' sélectionnable: ⊤ nom: 'deux')
			Phrase('option 3' sélectionnable: ⊤ nom: 'trois')
		]
	)
	Phrase(
		{
			'un': '😡'
			'deux': '🏀'
			'trois': '❤'
		}{option} ?? '?'
	)
\

 Le @Choice commence comme un @Text vide, et donc quand le projet démarre, on vérifie cela, et on montre les trois choix.
Une fois qu'un choix est fait, il devient l'un des trois noms @Phrase .

Pour montrer un emoji selon le choix, on peut utiliser une @Map pour convertir le nom en un emoji secret.
Quand on obtient une valeur d'une @Map, s'il n'y a pas de correspondance, cela s'évalue en \ø\, donc on utilise le \??\ pour choisir par défaut \'?'\ si l'option n'est pas dans la carte. 
Dans ce cas, cela ne peut jamais arriver, mais on n'est pas assez malin pour le savoir !
