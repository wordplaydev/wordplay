Susun karakter dari atas ke bawah

Jika sebuah @Row adalah untuk berdampingan, lalu sebuah @Stack Ini untuk dari atas ke bawah.
@Stack menempatkan setiap karakter di bawah karakter sebelumnya, seperti sebuah menara.

\
Group(Stack() [
    Phrase('satu')
    Phrase('dua')
    Phrase('tiga')
])
\

 Seperti @Row, @Stack juga bisa memiliki perataan dan jarak tepi (padding).
Coba ratakan semuanya ke sisi kiri:

\
Group(Stack('<' 0.25m) [
    Phrase('🐣 kecil')
    Phrase('🐥 sedang')
    Phrase('🐔 besar')
])
\

 The \'<'\ berarti / ratakan semuanya ke tepi kiri /.
Kamu juga bisa coba \'|'\ untuk tengah, atau \'>'\ untuk tepi kanan.
