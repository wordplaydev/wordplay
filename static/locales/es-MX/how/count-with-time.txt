Contar hacia arriba mientras pasa el tiempo

Muchos proyectos necesitan algo que crezca con el tiempo: un cronómetro, un puntaje o una cuenta regresiva.
Podemos crear un contador al combinar el flujo @Time con un @Reaction.

Un @Reaction tiene tres partes: un valor inicial, una cosa que observar y un nuevo valor cuando esa cosa cambia.
Aquí empezamos en \0\, observamos @Time y sumamos uno cada vez que el reloj avanza:

\
contar: 0 … ∆ Tiempo(1000ms) … contar + 1
Phrase(contar → '')
\

Cada segundo, @Time se activa, el @Reaction lo nota con \∆ Tiempo(1000ms)\, y \contar\ se convierte en \contar + 1\.
El \→ ''\ al final convierte el número en texto para que @Phrase pueda mostrarlo.

Puedes usar cualquier entrada que quieras, no solo el tiempo. Este contador cuenta el número de veces que se presiona Button():

\
contar: 0 … ∆ Botón() … contar + 1
Phrase(contar → '')
\

Cada vez que el flujo @Button cambia con un clic o un toque, la cuenta aumenta en uno.
