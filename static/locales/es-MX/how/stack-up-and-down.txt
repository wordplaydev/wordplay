Apila los caracteres de arriba hacia abajo

Si un  @Row  sirve para poner cosas lado a lado, entonces un  @Stack  sirve para poner cosas de arriba hacia abajo. @Stack  pone cada carácter debajo del anterior, como una torre.

\
Group(Stack() [Phrase('uno') Phrase('dos') Phrase('tres')])\

Como un  @Row , un  @Stack  también puede tener una alineación y un relleno. Intenta alinear todo por el lado izquierdo:

\
Group(
	Stack('<' 0.25m)
	[
		Phrase('🐣 pequeño')
		Phrase('🐥 mediano')
		Phrase('🐔 grande')
	]
)\

El \
'<'\ significa /alinear todo por el borde izquierdo/.También puedes probar \
'|'\ para centrar o \
'>'\ para el borde derecho.
