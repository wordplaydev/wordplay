Elige algo al azar de una lista.

¿Quieres que tu proyecto te sorprenda cada vez que se ejecute? Haz una lista de opciones y elige una con @Random.

@Random nos puede dar un número al azar, y a una lista se le puede buscar por número con \[n]\.
Junta esto para elegir un emoji al azar:

\
emojis: ['🌈' '🌟' '🎈' '🦄' '🍩']
Frase(emojis.azar())
\

 También puedes usar @Random con dos números, que elige un número entero entre ellos.
Por ejemplo, para elegir un emoji / nuevo / al azar cada segundo, mezcla @Time y un @Reaction:

\
emojis: ['🌈' '🌟' '🎈' '🦄' '🍩']
pick: emojis[1] … ∆ Tiempo(1000ms) … emojis[Azar(1 emojis.longitud())]
Frase(pick)
\

 Cada tic de @Time, el @Reaction elige una nueva sorpresa.
