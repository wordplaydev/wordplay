Hacer que un carácter se pueda mover

A veces es útil hacer que un @Phrase se pueda mover con un teclado, un ratón o un dedo.

Para hacer esto, podemos combinar @Phrase con @Placement:

\
Escenario(
	[Frase('muéveme' lugar: Ubicación())]
	lugar: Lugar(0m 0m -10m)
)
\

 Usar las flechas del teclado o hacer clic en el @Stage actualizará el @Placement, lo que hace que el @Phrase se mueva en esa dirección.

¿Sabías que @Placement se puede usar con / cualquier cosa / que reciba un @Place? 
Por ejemplo, un @Stage tiene un @Place que determina hacia dónde apunta su cámara.
Intentemos cambiar el lugar de un @Placement de un @Stage y veamos qué pasa.

\
Escenario(
  [
	Frase('🐈' lugar: Lugar(-2m 2m))
	Frase('🐈' lugar: Lugar(2m -2m))
	Frase('🐈' lugar: Lugar(-1m 3m))
  ]
  lugar: Ubicación(Lugar(0m 0m -10m))
)
\

¡Eso hace que la cámara se mueva! (Nota: iniciamos el @Placement con un \z\ value de \10m\ para que la cámara quede alejada de todo.)
