Haz que un carácter tiemble

A veces es útil que un carácter parezca que tiembla. Hay varias maneras de lograr eso.

Podemos usar  @Phrase/offset  con  @Random  y  @Time  para lograr eso.

\
offset: 0m … ∆ Time() … Random(-0.1m 0.1m)
Phrase('hola' offset: Place(offset 0m))\

Esto crea un valor llamado \
offset\ que cambia a un nuevo valor aleatorio cada vez que el reloj avanza. Luego, usa ese desplazamiento para mostrar el  @Phrase  desplazado por esa cantidad.

Si quisiéramos controlar el temblor con más precisión, podríamos usar una  @Sequence  para hacer una animación de temblor aleatorio que se repite.

\
Phrase(
	'hola'
	resting: Sequence(
		{
			0%: Pose(offset: Place(Random(-.2m .2m)))
			15%: Pose(offset: Place(Random(-.2m .2m)))
			60%: Pose(offset: Place(Random(-.2m .2m)))
			75%: Pose(offset: Place(Random(-.2m .2m)))
		}
		0.1s
	)
)\

Este ejemplo solo elige valores aleatorios una vez, pero los convierte en una secuencia que se repite.
