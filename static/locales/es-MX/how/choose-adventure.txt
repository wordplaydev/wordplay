Crea una aventura de texto

Un tipo divertido de juego es un juego de /elige tu propia aventura/, donde una persona jugadora avanza por una serie de opciones e intenta encontrar el camino a un final feliz. 

Para crear uno de estos, podemos usar  @Structure ,  @Key ,  @Reaction  y  @List  juntos para crear un conjunto de decisiones, cada una con un grupo de opciones, así:

\
¶ Esto crea una estructura de datos que guarda una opción y a qué decisión llevará ¶•Option(text•'' decision•#)
¶ Esta estructura de datos guarda una lista de opciones ¶•Decision(options: [
			Option
		])
¶ ¡Este es el contenido del juego! Cambia el texto de las opciones para crear ambiente y decisiones difíciles. Agrega opciones para crear una red de decisiones complicadas. ¶
decisions: [
		Decision([Option('inicio' 2)])
		Decision(
			[
				Option('izquierda' 3)
				Option('recto' 4)
				Option('derecha' 4)
			]
		)
		Decision([Option('ganar' 1)])
		Decision([Option('perder' 1)])
	]
¶ Convierte la tecla en un número, si lo es ¶
key: Key()
choice: key → #
¶ Este valor representa la decisión actual en la lista de arriba. Cuando se presiona la tecla, hacemos una de las siguientes cosas. Si solo hay una opción para esta decisión, entonces cambiamos la decisión actual a la decisión de destino de esa opción sin importar qué tecla se presionó. Si la tecla presionada está entre 1 y el número de opciones, entonces vamos a la decisión de destino de esa opción. Si no, dejamos la decisión actual igual. ¶
current•#: 1 … ∆ key … decisions[current].options.length() = 1 ? decisions[current].options[1].decision ((choice ≥ 1) & (choice ≤ decisions[current].options.length(
							))) ? decisions[current].options[choice].decision current
¶ Esto solo muestra las opciones como una pila de frases. ¡Puedes cambiar esto para agregar instrucciones, animaciones y otras cosas divertidas! ¶Stage(
	[
		Group(
			Stack()
			decisions[current].options.translate(
				ƒ(option) Phrase(option.text)
			)
		)
	]
)\

Este patrón parece complejo, pero lo único que hace en realidad es mostrar el conjunto actual de opciones y, cada vez que cambia una tecla, ir a la decisión de la opción elegida. ¡Diseñar un juego se trata de cambiar el contenido de arriba!
