ശബ്ദത്തെക്കൊണ്ട് വാക്കുകൾ പാടിക്കുക

പാലറ്റിലെ എല്ലാ @Instrument ഇനങ്ങളിലും, എന്തെങ്കിലും പറയാൻ കഴിയുന്നത് \വാദ്യോപകരണം.ശബ്ദം\ മാത്രമാണ്. അതിന് നിങ്ങളുടെ @Track എന്നത് ഒരു @Track/words നൽകൂ, അത് ഓരോ നോട്ടിനും ഒരു അക്ഷരം വീതം പാടും:

\
സംഗീതം(
	ട്രാക്ക്([1 2 3 5 3 1] വാക്കുകൾ: 'ലാ ലാ ലാ ലാ ലാ ലാ' വാദ്യം: വാദ്യോപകരണം.ശബ്ദം)
	വേഗത: 120beats/min
)
\

 ആറ് അക്ഷരങ്ങൾ, ആറ് നോട്ടുകൾ. ഇവിടെ സ്പേസുകൾ മാത്രമാണ് വ്യാകരണം — ഒരു അക്ഷരം എവിടെ നിൽക്കുന്നു, അടുത്തത് എവിടെ തുടങ്ങുന്നു എന്ന് അവ പറയുന്നു. വിശ്രമങ്ങൾക്ക് അക്ഷരം വേണ്ട, അതിനാൽ നിങ്ങൾ കേൾക്കുന്ന നോട്ടുകളിൽ തന്നെ വാക്കുകൾ വരും. നോട്ടുകളേക്കാൾ കുറച്ച് അക്ഷരങ്ങൾ എഴുതിയാൽ അവ വീണ്ടും തുടക്കം മുതൽ ആവർത്തിക്കും; ഒന്നും എഴുതിയില്ലെങ്കിൽ ശബ്ദം ഒരു / uh / ശബ്ദം പിടിച്ചുനിർത്തും, അതിനാൽ അത് എപ്പോഴും എന്തെങ്കിലും പാടും.

ഇവിടത്തെ എഴുത്ത് ഇംഗ്ലീഷ് അക്ഷരവിന്യാസമല്ല. ഇത് < ഇന്റർനാഷണൽ ഫൊണെറ്റിക് ആൽഫബെറ്റ്@https://en.wikipedia.org/wiki/International_Phonetic_Alphabet> ആണ്. അതിൽ ഓരോ അക്ഷരവും കൃത്യമായി ഒരു ശബ്ദമാണ്, ഓരോ ശബ്ദത്തിനും കൃത്യമായി ഒരു അക്ഷരമുണ്ട്. ഇംഗ്ലീഷ് അക്ഷരവിന്യാസത്തിന് ഇത് പറ്റില്ല — \o\ എന്ന അക്ഷരങ്ങൾ / പോകുക /, / do / ഒപ്പം / women / എന്നിവയിൽ മൂന്ന് വ്യത്യസ്ത ശബ്ദങ്ങളാണ് — അതുകൊണ്ട് ഇംഗ്ലീഷ് അക്ഷരവിന്യാസം വായിക്കുന്ന ശബ്ദം ഊഹിക്കേണ്ടിവരും, ഊഹം തെറ്റുകയും ചെയ്യും. നിങ്ങൾ ഏത് ഭാഷയിൽ എഴുതിയാലും വരികൾ ഒരുപോലെ പ്രവർത്തിക്കും എന്നും ഇതിനർത്ഥമുണ്ട്, കാരണം ഈ അക്ഷരങ്ങൾ നിങ്ങളുടെ ലിപിയെയല്ല, നിങ്ങളുടെ വായയുടെ ചലനത്തെയാണ് വിവരിക്കുന്നത്.

ഇവയിൽ മിക്കതിനും നിങ്ങളുടെ കീബോർഡിൽ കീ ഇല്ല, അതിനാൽ എഴുത്തുപെട്ടിക്ക് താഴെയുള്ള 🤖 അമർത്തുക. ശബ്ദത്തിന് ഉണ്ടാക്കാൻ കഴിയുന്ന എല്ലാ ശബ്ദങ്ങളും, അതുൾക്കൊള്ളുന്ന ഒരു വാക്കും, അത് കേൾപ്പിക്കുന്ന ഒരു ബട്ടണും അവിടെ കാണാം — അക്ഷരത്തിൽ തന്നെ അമർത്തിയാൽ അത് നിങ്ങളുടെ കോഡിൽ ടൈപ്പ് ആകും. ഒരു ശബ്ദം കേട്ടാൽ മാത്രമേ ശരിക്കും അറിയാൻ കഴിയൂ, ആ പാനലാണ് സഹായം; തുടങ്ങാൻ താഴെ പറയുന്നത് മതിയാകും.

സ്വരങ്ങളിൽ നിന്ന് തുടങ്ങാം. നിങ്ങൾക്ക് വേണ്ടതിൽ മിക്കതും ഈ പന്ത്രണ്ടെണ്ണം ഉൾക്കൊള്ളുന്നു, ഓരോന്നും അത് ഉൾക്കൊള്ളുന്ന ഒരു ഇംഗ്ലീഷ് വാക്കിനുള്ളിൽ കാണിച്ചിരിക്കുന്നു:

\a\ f / a / ther, \e\ b / ഇ / d, \i\ s / ee /, \o\ g / o /, \u\ b / oo / t, \ɛ\ h / ea / d, \ɪ\ b / i / t, \ɔ\ b / ou / ght, \ʊ\ b / oo / k, \æ\ c / a / t, \ʌ\ c / u / p, \ə\ / a / bout

ഒരു സ്വരം തനിയെ നിന്നാലും അത് ഒരു നല്ല അക്ഷരമാണ്. അവ തുടർച്ചയായി പാടുമ്പോൾ ഓരോന്നിന്റെയും വ്യത്യാസം ഏറ്റവും വ്യക്തമായി കേൾക്കാം:

\
സംഗീതം(
	ട്രാക്ക്([1 2 3 4 5] വാക്കുകൾ: 'അ ഇ ഉ എ ഒ' വാദ്യം: വാദ്യോപകരണം.ശബ്ദം)
	വേഗത: 90beats/min
)
\

 വ്യഞ്ജനങ്ങൾ മിക്കതും നിങ്ങൾ പ്രതീക്ഷിക്കുന്നതുപോലെ തന്നെയാണ് കാണപ്പെടുന്നത്: \p b t d k m n s f l r w\ ഇവയെല്ലാം ഇംഗ്ലീഷിലെപ്പോലെ തന്നെ ഉച്ചരിക്കപ്പെടുന്നു. ഇംഗ്ലീഷ് രണ്ട് അക്ഷരങ്ങൾ കൊണ്ട് എഴുതുന്ന ശബ്ദങ്ങളും, സ്ഥാനം മാറിയ ഒരു അക്ഷരവുമാണ് പഠിക്കേണ്ടത്. \ʃ\ ഓരോ നാലാമത്തെ താളത്തിലും — ഡൗൺബീറ്റിൽ — / sh /, \ʒ\ എന്നത് / s / എന്ന അക്ഷരങ്ങൾ / measure /, \θ\ എന്നത് / th / എന്ന അക്ഷരങ്ങൾ / thin /, \ð\ എന്നത് / th / എന്ന അക്ഷരങ്ങൾ / this /, \ŋ\ എന്നത് / ng / എന്ന അക്ഷരങ്ങൾ / sing /, കൂടാതെ \j\ എന്നത് / y / എന്ന അക്ഷരങ്ങൾ / yes /. ഇതിലൊന്ന് ഒരു സ്വരത്തിന് മുമ്പിൽ വെച്ചാൽ ഒരു വാക്കായി:

\
സംഗീതം(
	ട്രാക്ക്([5 5 3 3 1] വാക്കുകൾ: 'ഷി സി മി ലോ അപ്' വാദ്യം: വാദ്യോപകരണം.ശബ്ദം)
	വേഗത: 100beats/min
)
\

 ഒരു അക്ഷരം പല സ്വരങ്ങളിലായി നീട്ടിപ്പാടാനും കഴിയും. അതിന്റെ അവസാനം ഒരു ഹൈഫൺ ഇട്ടാൽ, ഓരോ ഹൈഫണിനും ഒരു സ്വരം കൂടി അത് നീണ്ടുനിൽക്കും. ഭജനകൾക്കും താരാട്ടുപാട്ടുകൾക്കും അവയുടെ രൂപം നൽകുന്നത് ഒരേ അക്ഷരത്തിലെ ഈ സ്വരനിരയാണ്:

\
സംഗീതം(
	ട്രാക്ക്([1 2 3 2 1] വാക്കുകൾ: 'ഗ്ലോ--- റി' വാദ്യം: വാദ്യോപകരണം.ശബ്ദം)
	വേഗത: 140beats/min
)
\

 മൂന്ന് ഹൈഫണുകൾ \glo\ നാല് സ്വരങ്ങളിലൂടെ കൊണ്ടുപോകുന്നു, അതിനുശേഷം \ri\ അവസാനത്തെ സ്വരത്തിൽ എത്തുന്നു. ശബ്ദം തിരിച്ചറിയാത്തതെല്ലാം അത് നിരസിക്കാതെ ഒഴിവാക്കും. അതിനാൽ പാട്ട് തകരാതെ നിങ്ങൾക്ക് പരീക്ഷിച്ചുനോക്കാം.
