Раздели проект на файлы кода

В проекте может быть больше одного @Source. Если длинный список данных лежит в отдельном файле,
главная программа остаётся короткой, и её легко прочитать с одного взгляда.

Допустим, тебе нужен список цветов для выбора. Создай второй @Source, дай ему имя 
/ цвета / и положи список туда. Значок \↑\ перед именем означает: / поделись этим
с остальной частью проекта /:

\
↑ colors/en: ['🔴' '🟠' '🟡' '🟢' '🔵' '🟣']
\

 Параметр / ru / после имени показывает, на каком языке написано имя. Так человек,
который читает твой проект на другом языке, поймёт, сможет ли он это прочитать.

Теперь вернись в свой главный @Source и подключи список с помощью @Borrow. Напиши 
\↓\ и имя другого файла кода:

\
↓ colors

Phrase(colors.random())
\🪲

 Внутри этого @Source, / цвета / теперь обозначает список, которым ты поделился. Всё, что ты отметишь
значком \↑\ , можно заимствовать так: список, число, функцию или структуру.

Чтобы создать новый @Source, нажми кнопку / Добавить файл кода / внизу проекта.
