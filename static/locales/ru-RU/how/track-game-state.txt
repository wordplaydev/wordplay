Следи за состоянием игры

Большинство игр следят за многими вещами по ходу игры: очки, положение игроков и другие детали очень важны.
Каждый раз, когда что-то вводят, это состояние меняется, и нам нужно показать новый результат в ответ.

Общий шаблон для любой игры делает три вещи:

• Определи структуру данных для состояния игры, чтобы хранить в ней всё состояние игры
• Определи реакцию, которая создаёт новое состояние игры на основе прежнего состояния каждый раз, когда появляется новый ввод
• Сделай @Stage вместе с @Group и @Phrase , чтобы показать состояние игры

Например, представим простую игру, в которой нужно вводить секретные слова в текстовое поле и получать одно очко каждый раз, когда секретное слово угадано:

\
•Game(secrets•[''] points•#)

state: Game(['cat' 'dog'] 0) … state.secrets.содержит(Чат()) … state.points: state.points + 1

Подмостки(
    state.points = state.secrets.длина() ? 
        [ Фраза("you win!")]
        [ Группа(Стопка() [ Фраза("guess my secret words") Фраза(`\state.secrets.length() - state.points\ more secrets`)])]
)
\

 Давай разберём это.

• Первая строка, \•игра(секреты•[''] точки2•#)\ говорит: / Создай структуру данных с именем \Game\ , которая хранит список секретов и очки /. \['']\ означает / список из любого количества слов /. Если тебе нужен список точной длины, можно назвать тип для каждого места в нём: \[# '']\ — это список из двух элементов: числа и слова.
• Вторая строка говорит: / Состояние игры начинается со списка секретов и нуля очков. Каждый раз, когда \Чат\ меняется, если введённое слово есть в списке секретов, создай новое состояние игры, где очков на одно больше /.
• Каждый раз, когда программа выполняется заново (когда \Чат\ меняется), показывай сцену. Если число очков равно числу секретов, покажи сцену победы. Если нет, покажи подсказку и число оставшихся секретов.

У этого примера есть некоторые проблемы:

• Если игрок угадает секретное слово несколько раз, он получит больше очков! Нашему состоянию игры, возможно, нужно ещё запоминать, что уже угадано, чтобы каждое слово считалось только один раз.
• Если игрок вводит несколько слов, нужно ли это засчитывать?

Более продуманные состояния игры и обновления игры помогут нам разобраться с такими случаями.
