Ставим текст рядом

Иногда нам нужно, чтобы текст стоял рядом в аккуратной строке.
Это можно сделать с помощью @Row, которая располагает всё в @Group слева направо.

\
Группа(Строка() [
    Фраза('🍎')
    Фраза('🍌')
    Фраза('🍇')
])
\

 Также @Row может выравнивать символы по верхнему, среднему или нижнему краю и добавлять между ними промежутки.
Вот те же фрукты, но выровненные по нижнему краю и с небольшими промежутками:

\
Группа(Строка('>' 0.5m) [
    Фраза('🍎' размер: 2m)
    Фраза('🍌' размер: 1m)
    Фраза('🍇' размер: 3m)
])
\

 Параметр \'>'\ говорит @Row выровнять всё по нижнему краю. Попробуй \'<'\ для верхнего края или \'|'\ для середины.
Параметр \0.5m\ — это промежуток между символами.
