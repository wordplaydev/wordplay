Создай текстовое приключение

Один из весёлых видов игр — это игра /«выбери своё приключение»/ , где игрок делает один выбор за другим и пытается найти путь к счастливому концу. 

Чтобы сделать такую игру, мы можем использовать @Structure, @Key, @Reaction и @List вместе, чтобы собрать набор решений. У каждого решения есть свои варианты, вот так:

\¶Это создаёт структуру данных, которая хранит выбор и то решение, к которому он ведёт¶
•option(текст2•'' решение•#)

¶Эта структура данных хранит список выборов¶
•решение2(варианты: [option])

¶Это содержимое игры! Измени текст в вариантах, чтобы создать атмосферу и трудный выбор. Добавляй варианты, чтобы получилась целая сеть непростых решений.¶
решения: [
		решение2([option('начать' 2)])
		решение2(
			[
				option('влево' 3)
				option('прямо' 4)
				option('вправо' 4)
			]
		)
		решение2([option('победа' 1)])
		решение2([option('поражение' 1)])
	]

¶Превратить ключ в число, если это число¶
ключ2: Ключ()
выбор: ключ2 → #

¶Это значение хранит текущее решение из списка выше. Когда нажимается клавиша, происходит одно из трёх. Если у этого решения только один выбор, мы переходим к целевому решению этого варианта, какая бы клавиша ни была нажата. Если нажатая клавиша — число от 1 до количества вариантов, мы переходим к целевому решению этого варианта. Во всех остальных случаях текущее решение остаётся прежним.¶
текущее•#: 1 …
	∆ ключ2 …
		решения[текущее].варианты.длина() = 1 ?
			решения[текущее].варианты[1].решение
			((1 ‥ решения[текущее].варианты.длина()) ∋ выбор) ?
				решения[текущее].варианты[выбор].решение
				текущее

¶Здесь варианты просто показываются стопкой фраз. Измени это, чтобы добавить подсказки, анимацию и другие интересные штуки!¶
Подмостки(
	[
		Группа(
			Стопка()
			решения[текущее].варианты.преобразовать(
				ƒ(вариант) Фраза(вариант.текст2)
			)
		)
	]
)

\

 Этот шаблон выглядит сложным, но на самом деле он просто показывает текущие варианты, а каждый раз, когда нажимается другая клавиша, переходит к решению выбранного варианта. Придумывать игру — это в основном менять содержимое вверху!
