Выбрать случайный элемент из списка

Хочешь, чтобы проект удивлял тебя при каждом запуске? Составь список вариантов и выбери один из них с помощью @Random.

@Random может дать нам случайное число, а элемент списка можно найти по номеру с помощью \[n]\.
Соедини их вместе, чтобы выбрать случайный эмодзи:

\
эмодзи: ['🌈' '🌟' '🎈' '🦄' '🍩']
Фраза(эмодзи.случайный())
\

 Ещё можно использовать @Random с двумя числами. Он выберет целое число между ними.
Например, чтобы выбирать / новый / случайный эмодзи каждую секунду, добавь @Time и @Reaction:

\
эмодзи: ['🌈' '🌟' '🎈' '🦄' '🍩']
выбрать: эмодзи[1] … ∆ Время(1000ms) … эмодзи[Случайное(1 эмодзи.длина())]
Фраза(выбрать)
\

 С каждым тиком @Time @Reaction выбирает новый сюрприз.
