Расставляй символы сверху вниз

Если @Row нужна, чтобы ставить рядом, то @Stack нужна, чтобы ставить сверху вниз.
@Stack ставит каждый символ под предыдущим, как башню.

\
Группа(Стопка() [
    Фраза('один')
    Фраза('два')
    Фраза('три')
])
\

 Как и @Row, @Stack тоже может иметь выравнивание и отступы.
Попробуй выровнять всё по левому краю:

\
Группа(Стопка('<' 0.25m) [
    Фраза('🐣 маленький')
    Фраза('🐥 средний')
    Фраза('🐔 большой')
])
\

 Параметр \'<'\ означает / выровнять всё по левому краю /.
Ещё можно попробовать \'|'\ для центра или \'>'\ для правого края.
