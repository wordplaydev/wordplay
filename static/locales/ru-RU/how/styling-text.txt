Оформи свой текст

Иногда нам нужно, чтобы текст выделялся. Мы можем сделать это с помощью / курсива /, * жирного шрифта * и многого другого!

Например, чтобы сделать текст курсивом, заключи его в косые черты //, как в //Привет//. Например:


\
Группа(Стопка() [
        Фраза(`Хочешь добавить в текст /курсив/?`)
        Фраза(`Он подходит, чтобы выделить главное или придать словам /особую изюминку/.`)
        Фраза(`Просто поставь косую черту (//) до и после слова или фразы, /вот так/.`)
    ]
)
\


@Phrase тоже может сделать текст жирным. Для этого заключи текст в звёздочки **, как в **Привет**. Например:

\
Группа(Стопка() [
        Фраза(`Хочешь, чтобы твой текст выделялся *жирным шрифтом*?`)
        Фраза(`Он отлично подходит, когда нужно *крикнуть погромче*.`)
        Фраза(`Просто поставь по одной звёздочке (**) вокруг слов, например *привет!*, и смотри, как текст заиграет.`)
      ]
)
\

@Phrase ещё может сделать текст ОЧЕНЬ жирным. Для этого заключи текст в знаки вставки ^^, как в ^^Привет^^. Например:

\
Группа(Стопка() [
        Фраза(`Сверхжирный шрифт ^самый крутой^, когда нужно выжать из текста максимум.`)
        Фраза(`Он похож на жирный, но ещё ^мощнее^. Для него обычно ставят по одному значку вставки вокруг слов (^^)`)
        Фраза(`Используй его для ^заголовков^ или ^больших идей^.`)
    ]
)
\

 И наконец, @Phrase может сделать текст подчёркнутым. Для этого заключи текст в нижние подчёркивания __, как в __Привет__. Например:

\
Группа(Стопка() [
        Фраза(`Подчёркивание _очень выручает_, когда хочешь оставить текст аккуратным, но всё равно выделить его.`)
        Фраза(`Поставь по одному знаку подчёркивания (__) до и после текста, _вот так_, и получится чистое, аккуратное выделение.`)
        Фраза(`Оно _отлично_ подходит, чтобы выразить мысль и не перестараться, не будучи _слишком громким_.`)
    ]
)
\
