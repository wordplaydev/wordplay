நேரம் செல்லச் செல்ல எண்ணுங்கள்

பல திட்டங்களுக்கு காலப்போக்கில் வளரும் ஒன்று தேவைப்படுகிறது — ஒரு நேரக்கணக்கி, ஒரு மதிப்பெண், ஒரு எண்ணிறக்கம்.
நாம் ஒரு எண்ணிக்கையாளரை உருவாக்க @Time நீரோட்டத்தை ஒரு @Reaction உடன் இணைக்கலாம்.

ஒரு @Reaction இதற்கு மூன்று பகுதிகள் உள்ளன: ஒரு தொடக்க மதிப்பு, கவனிக்க வேண்டிய ஒன்று, மற்றும் அது மாறும்போது கிடைக்கும் புதிய மதிப்பு.
இங்கே, நாம் \0\ இல் தொடங்குகிறோம், @Time ஐ கவனிக்கிறோம், மற்றும் கடிகாரம் ஒவ்வொரு முறையும் ஓசையிடும்போது ஒன்றைக் கூட்டுகிறோம்:

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 ஒவ்வொரு வினாடியும், @Time செயல்படுகிறது, @Reaction அதை \∆ Time(1000ms)\ மூலம் கவனிக்கிறது, மற்றும் \count\ ஆகிறது \count + 1\ உடன் இணைக்கலாம்.
இந்த \→ ''\ இறுதியில் இருப்பது எண்ணை உரையாக மாற்றுகிறது, இதனால் @Phrase அதைக் காட்ட முடியும்.

நீங்கள் விரும்பும் எந்த உள்ளீட்டையும் பயன்படுத்தலாம், நேரத்தை மட்டும் அல்ல. இந்தக் கவுண்டர், பட்டன்() அழுத்தங்களின் எண்ணிக்கையைக் கணக்கிடுகிறது:

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 ஒவ்வொரு முறையும் @Button ஒரு கிளிக் அல்லது தட்டுவதன் மூலம் ஸ்ட்ரீம் மாறும்போது, எண்ணிக்கை ஒன்றால் அதிகரிக்கிறது.
