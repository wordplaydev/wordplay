讓整個舞台看起來像老電影、電視或水中

電影會改變整個場景的樣子：回憶畫面會變得柔和明亮，舊新聞影片會有刮痕又灰灰的，電視會出現雜訊，水底的東西則會泛起波紋、變成藍色。
我們也可以這樣做，只要給一個 @Stage 一份 @Effect 的清單。

這是透過水看到的場景。

\
舞台(
	[短語('🐠') 短語('🌿' 位置: 位置(1m -1m))]
	效果: [波浪(0.15m) 染色(色彩(55% 45 220°) 70%) 霧氣(40% 色彩(70% 30 200°))]
)
\

 每個效果只做一件事。 @Wave 讓畫面泛起波紋， @Tint 把所有東西染成同一種顏色，而 @Haze 則在上面蓋一層飄動的霧。
合在一起，它們就像水一樣。效果會依照清單中的順序套用，所以後面的效果會改變前面效果的結果。

有十種效果可以組合： @Blur、 @Grade、 @Tint、 @Haze、 @Grain、 @Scanlines、 @Wave、 @Damage、 @Flicker，還有 @Vignette 的清單。
這是一部老電影： @Grade 先去掉顏色，再用 @Damage、 @Grain，還有 @Flicker 讓畫面看起來破舊又不穩定。

\
舞台(
	[短語('THE END')]
	效果: [調色(對比: 130% 飽和度: 0%) 損壞(70% 50%) 顆粒(25%) 閃動(15% 2) 暗角(60%)]
)
\

 這是一台訊號中斷的電視。

\
舞台(
	[短語('channel 3')]
	效果: [掃描線(40% 速度: 1) 顆粒(50% 大小: 2) 閃動(20%)]
)
\

 如果想一再使用同一種外觀，可以做一個函式，讓它回傳效果的清單。
函式的輸入就成了這個外觀自己的設定。這一個會越往深處越模糊。

\
ƒ underwater(depth•%) [
	波浪(0.2m · depth)
	染色(色彩(55% 45 220°) depth)
	模糊(0.03m · depth)
]

舞台([短語('🐠')] 效果: underwater(80%))
\

 外觀也可以隨著遊戲的狀態改變。
在這裡，當玩家只剩一條命時，舞台的邊緣會變模糊變暗；命比較多時，又會恢復清楚。

\
lives: 3 … ∆ 鑰匙() … lives - 1

舞台(
	[短語(lives → '')]
	效果: lives < 2 ? [模糊(0.05m) 暗角(70% 色彩(30% 80 30°))] []
)
\

 效果會蓋住舞台上的東西，但不會影響舞台的 @Stage.overlay，所以分數或按鈕還是清楚好讀。

讓整個舞台搖晃，像地震一樣，根本不是效果： @Stage 可以像其他輸出一樣移動，所以幫它加上一個 @Sequence 的清單。

\
舞台([短語('🏠')] 休息時: 排序.抖動(0.5s 計數: 4x))
\

 有些效果動得很快。如果有人已經請裝置減少動態效果，所有效果都會保持不動。
@Flicker 每秒最多只會閃爍幾次，不管你要求多快都一樣，因為快速閃爍可能會傷害人。
