顯示可選的選項

有時你想在螢幕上顯示一系列選項，並根據觀眾的選擇執行相應的操作。為此，我們需要做兩件事：

• 一個或多個「 @Phrase 」，這些必須標記為可選取，並擁有唯一的名稱（例如 \Phrase('選項 1' 可選擇的: ⊤ 名字: '一')\）
• 一個 @Choice，這會變成最近一次選到的 @Phrase 名稱。

例如，這裡我們顯示三個選項，每個選項都有一個唯一的名稱。

\
option: Choice()

Group(
	Stack() [
		Phrase('選項 1' 可選擇的: ⊤ 名字: '一')
		Phrase('選項 2' 可選擇的: ⊤ 名字: '二')
		Phrase('選項 3' 可選擇的: ⊤ 名字: '三')
		Phrase(option)
	]
)
\

 每次選一個，最後 @Phrase 顯示所選的名稱。

你可以使用這個模式來響應使用者選擇。例如，我們可以修改上面的項目，讓它根據使用者選擇顯示一個秘密表情符號：

\
option: Choice()

option = '' ?
	Group(
		Stack() [
			Phrase('選項 1' 可選擇的: ⊤ 名字: '一')
			Phrase('選項 2' 可選擇的: ⊤ 名字: '二')
			Phrase('選項 3' 可選擇的: ⊤ 名字: '三')
		]
	)
	Phrase(
		{
			'一': '😡'
			'二': '🏀'
			'三': '❤'
		}{option} ?? '？'
	)
\

 這個 @Choice 一開始是空的 @Text，所以當工程開始時，我們會檢查這一點，並顯示三個選項。
一旦做出選擇，它就會變成三個 @Phrase 名稱之一。

為了根據選擇顯示表情符號，我們可以用一個 @Map 把名稱轉換成一個秘密表情符號。
當我們從 @Map 取得一個值時，如果找不到符合的，它就會得到 \ø\，所以我們用 \??\ 在這個選項不在對映裡時，預設變成 \'？'\ 。 
在這種情況下，這種事永遠不會發生，但我們的程式還不夠聰明，不知道這一點！
