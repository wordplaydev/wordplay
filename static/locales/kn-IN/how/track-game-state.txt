ಆಟದ ಸ್ಥಿತಿಯ ಲೆಕ್ಕ ಇಡಿ

ಹೆಚ್ಚಿನ ಆಟಗಳಲ್ಲಿ ಆಟ ಮುಂದುವರೆದಂತೆ ಹಲವು ವಿಷಯಗಳನ್ನು ಗಮನಿಸಬೇಕಾಗುತ್ತದೆ: ಅಂಕಗಳು, ಆಟಗಾರರ ಸ್ಥಾನಗಳು, ಮತ್ತು ಇತರ ವಿವರಗಳು ಎಲ್ಲವೂ ಮುಖ್ಯ.
ಪ್ರತಿ ಬಾರಿ ಏನಾದರೂ ಇನ್‌ಪುಟ್ ಬಂದಾಗ, ಆ ಸ್ಥಿತಿ ಬದಲಾಗುತ್ತದೆ, ಮತ್ತು ಆಗ ನಾವು ಪ್ರತಿಕ್ರಿಯೆಯಾಗಿ ಹೊಸ ಔಟ್‌ಪುಟ್ ತೋರಿಸಬೇಕಾಗುತ್ತದೆ.

ಯಾವುದೇ ಆಟಕ್ಕೆ ಸಾಮಾನ್ಯ ಮಾದರಿಯು ಮೂರು ಕೆಲಸಗಳನ್ನು ಮಾಡುತ್ತದೆ:

• ಇಡೀ ಆಟದ ಸ್ಥಿತಿಯನ್ನು ಸಂಗ್ರಹಿಸಲು ಒಂದು ಆಟದ ಸ್ಥಿತಿಯ ದತ್ತ ರಚನೆಯನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿ
• ಹೊಸ ಇನ್‌ಪುಟ್ ಬಂದಾಗಲೆಲ್ಲ ಹಿಂದಿನ ಆಟದ ಸ್ಥಿತಿಯ ಆಧಾರದ ಮೇಲೆ ಹೊಸ ಆಟದ ಸ್ಥಿತಿಯನ್ನು ಮಾಡುವ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿ
• ಒಂದು @Stage ಜೊತೆಗೆ @Group ಮತ್ತು @Phrase ಅನ್ನು ಮಾಡಿ, ಆಟದ ಸ್ಥಿತಿಯನ್ನು ತೋರಿಸಲು

ಉದಾಹರಣೆಗೆ, ಒಂದು ಸರಳ ಆಟವನ್ನು ಕಲ್ಪಿಸಿಕೊಳ್ಳೋಣ, ಇದರಲ್ಲಿ ರಹಸ್ಯ ಪದಗಳನ್ನು ಪಠ್ಯ ಪೆಟ್ಟಿಗೆಯಲ್ಲಿ ಟೈಪ್ ಮಾಡುವುದು ಸೇರಿದೆ, ಮತ್ತು ಪ್ರತಿ ಬಾರಿ ರಹಸ್ಯ ಪದವನ್ನು ಸರಿಯಾಗಿ ಊಹಿಸಿದಾಗ ಒಂದು ಅಂಕ ಸಿಗುತ್ತದೆ:

\
•Game(secrets•[''] points•#)

state: Game(['ಬೆಕ್ಕು' 'ನಾಯಿ'] 0) … state.secrets.has(Chat()) … state.points: state.points + 1

Stage(
    state.points = state.secrets.length() ? 
        [ Phrase("ನೀವು ಗೆದ್ದಿರಿ!")]
        [ Group(Stack() [ Phrase("ನನ್ನ ರಹಸ್ಯ ಪದಗಳನ್ನು ಊಹಿಸಿ") Phrase(`\state.secrets.length() - state.points\ ಇನ್ನಷ್ಟು ರಹಸ್ಯಗಳು`)])]
)
\

 ಇದನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ.

• ಮೊದಲ ಸಾಲು, \•ಆಟ(ಗುಟ್ಟುಗಳು•[''] ಅಂಕಗಳು•#)\ ಹೇಳುತ್ತದೆ, / ರಹಸ್ಯಗಳ ಪಟ್ಟಿ ಮತ್ತು ಅಂಕಗಳನ್ನು ಸಂಗ್ರಹಿಸುವ \Game\ ಎಂಬ ದತ್ತ ರಚನೆಯನ್ನು ಮಾಡಿ/. ಈ \['']\ ಎಂದರೆ / ಎಷ್ಟಾದರೂ ಪದಗಳ ಪಟ್ಟಿ/. ಬದಲಿಗೆ ನಿಖರವಾದ ಉದ್ದದ ಪಟ್ಟಿ ಬೇಕಿದ್ದರೆ, ಅದರ ಪ್ರತಿ ಸ್ಥಳಕ್ಕೂ ಒಂದೊಂದು ಮಾದರಿಯನ್ನು ಹೆಸರಿಸಬಹುದು: \[# '']\ ಎಂಬುದು ಎರಡು ವಸ್ತುಗಳ ಪಟ್ಟಿ, ಒಂದು ಸಂಖ್ಯೆ ಮತ್ತು ನಂತರ ಒಂದು ಪದ.
• ಎರಡನೇ ಸಾಲು ಹೇಳುತ್ತದೆ / ಆಟದ ಸ್ಥಿತಿಯು ರಹಸ್ಯಗಳ ಪಟ್ಟಿ ಮತ್ತು ಸೊನ್ನೆ ಅಂಕಗಳಿಂದ ಆರಂಭವಾಗುತ್ತದೆ. ಪ್ರತಿ ಬಾರಿ \ಚಾಟ್ಮಾಡಿ\ ಬದಲಾದಾಗ, ನಮೂದಿಸಿದ ಪದ ರಹಸ್ಯಗಳ ಪಟ್ಟಿಯಲ್ಲಿ ಇದ್ದರೆ, ಅಂಕಗಳನ್ನು ಒಂದರಿಂದ ಹೆಚ್ಚಿಸಿ ಹೊಸ ಆಟದ ಸ್ಥಿತಿಯನ್ನು ಮಾಡಿ/ ಜೊತೆ ಸೇರಿಸಿ ಒಂದು ಎಣಿಕೆಗಾರವನ್ನು ಕಟ್ಟಬಹುದು.
• ಪ್ರೋಗ್ರಾಮ್ ಪುನಃ ಲೆಕ್ಕಾಚಾರ ಮಾಡುವ ಪ್ರತಿ ಬಾರಿ ( \ಚಾಟ್ಮಾಡಿ\ ಬದಲಾದಾಗ), ಒಂದು ವೇದಿಕೆಯನ್ನು ತೋರಿಸಿ. ಅಂಕಗಳ ಸಂಖ್ಯೆ ರಹಸ್ಯಗಳ ಸಂಖ್ಯೆಗೆ ಸಮನಾಗಿದ್ದರೆ, ಗೆಲುವಿನ ವೇದಿಕೆಯನ್ನು ತೋರಿಸಿ. ಇಲ್ಲದಿದ್ದರೆ, ಒಂದು ಸೂಚನೆಯನ್ನು ಮತ್ತು ಉಳಿದಿರುವ ರಹಸ್ಯಗಳ ಸಂಖ್ಯೆಯನ್ನು ತೋರಿಸಿ.

ಈ ಉದಾಹರಣೆಯಲ್ಲಿ ಕೆಲವು ತೊಂದರೆಗಳಿವೆ:

• ಆಟಗಾರ ಒಂದೇ ರಹಸ್ಯ ಪದವನ್ನು ಹಲವು ಬಾರಿ ಊಹಿಸಿದರೆ, ಅವರಿಗೆ ಹೆಚ್ಚು ಅಂಕಗಳು ಸಿಗುತ್ತವೆ! ನಮ್ಮ ಆಟದ ಸ್ಥಿತಿಯು ಏನನ್ನು ಊಹಿಸಲಾಗಿದೆ ಎಂಬುದನ್ನೂ ನೆನಪಿಡಬೇಕಾಗಬಹುದು, ಆಗ ಪ್ರತಿ ಪದವನ್ನು ಎರಡು ಬಾರಿ ಮಾತ್ರ ಎಣಿಸಲಾಗುತ್ತದೆ.
• ಆಟಗಾರ ಹಲವು ಪದಗಳನ್ನು ನಮೂದಿಸಿದರೆ, ಅದನ್ನು ಎಣಿಸಬೇಕೆ?

ಈ ಸಂದರ್ಭಗಳನ್ನು ನಿಭಾಯಿಸಲು ಇನ್ನಷ್ಟು ಉತ್ತಮವಾದ ಆಟದ ಸ್ಥಿತಿಗಳು ಮತ್ತು ಆಟದ ಬದಲಾವಣೆಗಳು ನೆರವಾಗುತ್ತವೆ.
