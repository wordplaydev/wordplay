ಪ್ರತಿ ಅಕ್ಷರಕ್ಕೂ ಅದರದೇ ಆದ ಬಣ್ಣ ಕೊಡಿ

ಒಂದು @Phrase ತನ್ನ ಪ್ರತಿಯೊಂದು ಗ್ಲಿಫ್‌ಗೂ ಬೇರೆ ಬೇರೆ @Pose ಕೊಡಬಹುದು, ಇದಕ್ಕಾಗಿ @Phrase/poses ಬಳಸಿ.
ಮೊದಲ ಗ್ಲಿಫ್‌ಗೆ ಮೊದಲ ಭಂಗಿ, ಎರಡನೇ ಗ್ಲಿಫ್‌ಗೆ ಎರಡನೇ ಭಂಗಿ ಸಿಗುತ್ತದೆ. ಭಂಗಿಗಳು ಮುಗಿದಾಗ, ಮತ್ತೆ ಮೊದಲಿನಿಂದ ಪ್ರಾರಂಭವಾಗುತ್ತದೆ.

ಇಲ್ಲಿ ಮೂರು ಬಣ್ಣಗಳು ಸರದಿಯಲ್ಲಿ ಬರುವ ಒಂದು ಪಾರ್ಟಿ ಪಠ್ಯ ಇದೆ:

\
ನುಡಿಗಟ್ಟು(
	'party time!'
	ಮುಖ: 'Luckiest Guy'
	ಭಂಗಿಗಳು: [
		ಭಂಗಿ(ಬಣ್ಣ: ಬಣ್ಣ(25% 70 250°))
		ಭಂಗಿ(ಬಣ್ಣ: ಬಣ್ಣ(50% 80 300°))
		ಭಂಗಿ(ಬಣ್ಣ: ಬಣ್ಣ(58% 90 60°))
	]
)
\

 ಖಾಲಿ ಜಾಗಗಳೂ ಗ್ಲಿಫ್‌ಗಳೇ ಎಂದು ಎಣಿಕೆಯಾಗುತ್ತವೆ. ಹಾಗಾಗಿ ಬಣ್ಣಗಳು ಪದಗಳ ನಡುವೆಯೂ ಸರದಿಯಲ್ಲಿ ಮುಂದುವರಿಯುತ್ತವೆ.
ಈ ಬಣ್ಣಗಳು ವರ್ಣದಲ್ಲಷ್ಟೇ ಅಲ್ಲ, ಹೊಳಪಿನಲ್ಲೂ ಬೇರೆ ಬೇರೆಯಾಗಿವೆ. ಹಾಗಾಗಿ ಬಣ್ಣಗಳನ್ನು ಬೇರೆ ರೀತಿಯಲ್ಲಿ ನೋಡುವವರೂ ಅವುಗಳನ್ನು ಬೇರ್ಪಡಿಸಿ ಗುರುತಿಸಬಹುದು.

ಭಂಗಿಗಳು ಬಣ್ಣಕ್ಕಿಂತ ಹೆಚ್ಚನ್ನು ಮಾಡಬಲ್ಲವು. ಪ್ರತಿ ಗ್ಲಿಫ್ ತನ್ನ ಮಧ್ಯಭಾಗದ ಸುತ್ತ ವಾಲುತ್ತದೆ, ದೊಡ್ಡದಾಗುತ್ತದೆ, ಮಸುಕಾಗುತ್ತದೆ ಮತ್ತು ಚಲಿಸುತ್ತದೆ. ಹೀಗೆ ನಾವು ಅಕ್ಷರಗಳನ್ನು ಪುಟಿಯುವಂತೆ ಮಾಡಬಹುದು:

\
ನುಡಿಗಟ್ಟು(
	'bounce'
	ಮುಖ: 'Luckiest Guy'
	ಭಂಗಿಗಳು: [
		ಭಂಗಿ(ಬಣ್ಣ: ಬಣ್ಣ(25% 70 250°) ತಿರುಗುವಿಕೆ: -10° ಆಫ್‌ಸೆಟ್: ಸ್ಥಳ(0m 0.1m))
		ಭಂಗಿ(ಬಣ್ಣ: ಬಣ್ಣ(58% 90 60°) ತಿರುಗುವಿಕೆ: 10° ಅಪಾರದರ್ಶಕತೆ: 0.6)
	]
)
\

 ಭಂಗಿಗಳು ರೂಪಿತ ಪಠ್ಯದೊಂದಿಗೂ ಕೆಲಸ ಮಾಡುತ್ತವೆ. ಬೇರೆ ಯಾವುದೇ ಇನ್‌ಪುಟ್‌ನಂತೆ, ಅವು ಇತರ ಮೌಲ್ಯಗಳನ್ನು ಅವಲಂಬಿಸಿ ಬದಲಾಗಬಹುದು.
ಈ ಬೆದರಿಕೆ ಪತ್ರ ಪ್ರತಿ ಕಾಲು ಸೆಕೆಂಡಿಗೊಮ್ಮೆ ಹೊಸ ವಾಲುವಿಕೆಯನ್ನು ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ:

\
tilt: 0° … ∆ ಸಮಯ(250ms) … ಯಾದೃಚ್ಛಿಕ(-15° 15°)
ನುಡಿಗಟ್ಟು(
	`*ransom* /note/`
	ಮುಖ: 'Courier Prime'
	ಭಂಗಿಗಳು: [
		ಭಂಗಿ(ತಿರುಗುವಿಕೆ: tilt ಆಫ್‌ಸೆಟ್: ಸ್ಥಳ(0m 0.05m))
		ಭಂಗಿ(ತಿರುಗುವಿಕೆ: -tilt ಅಳತೆ: 1.2)
		ಭಂಗಿ(ತಿರುಗುವಿಕೆ: tilt ÷ 2 ಆಫ್‌ಸೆಟ್: ಸ್ಥಳ(0m -0.05m))
	]
)
\
