ಸಮಯ ಕಳೆದಂತೆ ಎಣಿಸಿ

ಹಲವು ಯೋಜನೆಗಳಿಗೆ ಸಮಯ ಕಳೆದಂತೆ ಬೆಳೆಯುವ ಒಂದು ವಸ್ತು ಬೇಕಾಗುತ್ತದೆ — ಒಂದು ಟೈಮರ್, ಒಂದು ಅಂಕ, ಅಥವಾ ಇಳಿಕೆ ಎಣಿಕೆ.
ನಾವು @Time ಸ್ಟ್ರೀಮ್ ಅನ್ನು @Reaction ಜೊತೆ ಸೇರಿಸಿ ಒಂದು ಎಣಿಕೆಗಾರವನ್ನು ಕಟ್ಟಬಹುದು.

ಒಂದು @Reaction ಗೆ ಮೂರು ಭಾಗಗಳಿವೆ: ಒಂದು ಆರಂಭದ ಮೌಲ್ಯ, ಗಮನಿಸಬೇಕಾದ ಒಂದು ವಸ್ತು, ಮತ್ತು ಆ ವಸ್ತು ಬದಲಾದಾಗ ಬರುವ ಹೊಸ ಮೌಲ್ಯ.
ಇಲ್ಲಿ, ನಾವು \0\ ನಿಂದ ಆರಂಭಿಸುತ್ತೇವೆ, @Time ಅನ್ನು ಗಮನಿಸುತ್ತೇವೆ, ಮತ್ತು ಗಡಿಯಾರ ಪ್ರತಿ ಬಾರಿ ಟಿಕ್ ಮಾಡಿದಾಗ ಒಂದನ್ನು ಸೇರಿಸುತ್ತೇವೆ:

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 ಪ್ರತಿ ಸೆಕೆಂಡಿಗೊಮ್ಮೆ, @Time ಚಾಲನೆಗೊಳ್ಳುತ್ತದೆ, @Reaction ಅದನ್ನು \∆ Time(1000ms)\ ಮೂಲಕ ಗಮನಿಸುತ್ತದೆ, ಮತ್ತು \count\ ಆಗುತ್ತದೆ \count + 1\ ಜೊತೆ ಸೇರಿಸಿ ಒಂದು ಎಣಿಕೆಗಾರವನ್ನು ಕಟ್ಟಬಹುದು.
ಈ \→ ''\ ಕೊನೆಯಲ್ಲಿ ಇರುವುದು ಸಂಖ್ಯೆಯನ್ನು ಪಠ್ಯವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ, ಇದರಿಂದ @Phrase ಅದನ್ನು ತೋರಿಸಬಹುದು.

ನೀವು ಕೇವಲ ಸಮಯವನ್ನು ಮಾತ್ರವಲ್ಲದೆ, ನಿಮಗೆ ಬೇಕಾದ ಯಾವುದೇ ಇನ್‌ಪುಟ್ ಅನ್ನು ಬಳಸಬಹುದು. ಈ ಕೌಂಟರ್ ಬಟನ್() ಒತ್ತುವಿಕೆಯ ಸಂಖ್ಯೆಯನ್ನು ಎಣಿಸುತ್ತದೆ:

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 ಪ್ರತಿ ಬಾರಿಯೂ @Button ಒಂದು ಕ್ಲಿಕ್ ಅಥವಾ ಟ್ಯಾಪ್ ಮೂಲಕ ಸ್ಟ್ರೀಮ್ ಬದಲಾದರೆ, ಎಣಿಕೆ ಒಂದರಿಂದ ಹೆಚ್ಚಾಗುತ್ತದೆ.
