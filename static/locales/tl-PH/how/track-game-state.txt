Subaybayan ang estado ng laro

Karamihan sa mga laro ay sumusubaybay ng maraming bagay habang umuusad ang laro: ang puntos, posisyon ng manlalaro, at iba pang detalye ay mahalaga.Tuwing may input, nagbabago ang estadong iyon, at pagkatapos, gusto nating magpakita ng bagong output bilang tugon.

May pangkalahatang pattern para sa anumang laro na gumagawa ng tatlong bagay:

• Gumawa ng estruktura ng datos para sa estado ng laro, para itago ang lahat ng estado ng laro• Gumawa ng reaksyon na gumagawa ng bagong estado ng laro base sa naunang estado, tuwing may bagong input• Gumawa ng  @Stage  na may  @Group  at  @Phrase  para ipakita ang estado ng laro

Halimbawa, isipin natin ang isang simpleng laro kung saan nagta-type ka ng mga lihim na salita sa isang text box, at nakakakuha ka ng isang puntos tuwing tama ang hulang lihim na salita:

\•Game(secrets•[''] points•#)
state: Game(['pusa' 'aso'] 0) … state.secrets.has(Chat()) … state.points:state.points + 1
Stage(
	state.points = state.secrets.length() ? [
			Phrase("panalo ka!")
		] [
			Group(
				Stack()
				[
					Phrase("hulaan ang aking mga lihim na salita")
					Phrase(
						`\state.secrets.length() - state.points\ pang lihim`
					)
				]
			)
		]
)\

Suriin natin ito nang paisa-isa.

• Ang unang linya, \•laro(mgaLihim•[''] mgaPuntos•#)\ ay nagsasabing, /Gumawa ng estruktura ng datos na tinatawag na \Game\ na nag-iimbak ng listahan ng mga lihim at puntos/. Ang \[
	''
]\ ay nangangahulugang /isang listahan ng anumang bilang ng mga salita/. Kung gusto mo ng listahan na may eksaktong haba sa halip, maaari kang magbigay ng pangalan ng uri para sa bawat puwesto rito: \[
	#'']\ ay listahan ng dalawang bagay, isang numero at pagkatapos ay isang salita.• Sinasabi ng pangalawang linya na /Ang estado ng laro ay nagsisimula sa isang listahan ng mga sikreto at zero na puntos. Tuwing nagbabago ang \Makipagchat\ , kung ang salitang ipinasok ay nasa listahan ng mga sikreto, gumawa ng bagong estado ng laro na may puntos na dinagdagan ng isa/.• Tuwing muling sinusuri ng programa (kapag nagbago ang \Makipagchat\ ), nagpapakita ito ng entablado. Kung ang bilang ng puntos ay katumbas ng bilang ng mga sikreto, ipinapakita ang isang entabladong pandaigdig. Kung hindi, ipinapakita ang isang paalala at ang bilang ng mga sikretong natitira.

May ilang problema ang halimbawang ito:

• Kung hulaan nila ang isang sikretong salita ng maraming beses, mas maraming puntos ang makukuha nila! Maaaring kailangan din ng ating estado ng laro na tandaan kung ano ang nahulaan na, para bawat salita ay bibilangin lamang nang dalawang beses.• Kung nagpasok ang manlalaro ng maraming salita, dapat ba itong bilangin?

Ang mas masusing mga estado ng laro at mga pag-update ng laro ay makakatulong sa atin na hawakan ang mga kasong ito.
