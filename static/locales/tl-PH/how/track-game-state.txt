Subaybayan ang estado ng laro

Karamihan sa mga laro ay sumusubaybay sa maraming bagay habang umuusad ang laro: mahalaga ang puntos, posisyon ng manlalaro, at iba pang detalye.
Tuwing may input, nagbabago ang estado, at pagkatapos gusto nating ipakita ang bagong output, bilang tugon.

May pangkalahatang pattern para sa anumang laro na gumagawa ng tatlong bagay:

• Gumawa ng istrukturang pang-data ng estado ng laro, para itago ang lahat ng estado ng laro
• Gumawa ng reaksyon na gumagawa ng bagong estado ng laro base sa dating estado ng laro, tuwing may bagong input
• Gumawa ng @Stage kasama ang @Group at @Phrase para ipakita ang estado ng laro

Halimbawa, isipin natin ang isang simpleng laro kung saan nagta-type ka ng mga lihim na salita sa isang text box, at nakakakuha ka ng isang puntos tuwing tama ang hulang lihim na salita:

\
•Game(secrets•[''] points•#)

state: Game(['pusa' 'aso'] 0) … state.secrets.has(Chat()) … state.points: state.points + 1

Stage(
    state.points = state.secrets.length() ? 
        [ Phrase("panalo ka!")]
        [ Group(Stack() [ Phrase("hulaan ang aking mga lihim na salita") Phrase(`\state.secrets.length() - state.points\ pang lihim`)])]
)
\

 Suriin natin ito nang paisa-isa.

• Sinasabi ng unang linya, \•laro(mgaLihim•[''] mgaPuntos•#)\ na, / Gumawa ng istrukturang pang-data na tinatawag na \Game\ na nag-iimbak ng listahan ng mga sikreto at puntos /. Ang \['']\ ay nangangahulugang / listahan ng kahit anong bilang ng mga salita /. Kung gusto mo ng listahan na may eksaktong haba, maaari kang magbigay ng uri para sa bawat puwesto rito: \[# '']\ ay listahan ng dalawang bagay, isang numero pagkatapos ay isang salita.
• Sinasabi ng ikalawang linya / Nagsisimula ang estado ng laro sa isang listahan ng mga sikreto at zero na puntos. Tuwing nagbabago ang \Makipagchat\ , kung ang salitang inilagay ay nasa listahan ng mga sikreto, gumawa ng bagong estado ng laro na may puntos na dinagdagan ng isa /.
• Tuwing muling sinusuri ng programa (kapag nagbabago ang \Makipagchat\ ), magpakita ng entablado. Kung ang bilang ng puntos ay katumbas ng bilang ng mga sikreto, ipakita ang isang nanalong entablado. Kung hindi, magpakita ng prompt at ng bilang ng mga natitirang sikreto.

May ilang problema ang halimbawang ito:

• Kung nahulaan nila ang isang sikretong salita nang maraming beses, mas marami silang makukuhang puntos! Maaaring kailangan ng estado ng ating laro na tandaan din kung ano ang nahulaan na, para bawat salita ay bilangin lamang nang dalawang beses.
• Kung maglagay ang manlalaro ng maraming salita, dapat ba itong bilangin?

Ang mas masusing mga estado ng laro at mga pag-update ng laro ay makakatulong sa atin na hawakan ang mga kasong ito.
