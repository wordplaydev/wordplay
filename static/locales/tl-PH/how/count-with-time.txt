Magbilang habang lumilipas ang oras

Maraming proyekto ang nangangailangan ng isang bagay na lumalaki sa paglipas ng panahon — isang orasan, isang iskor, o isang pagbibilang pababa.
Maaari tayong gumawa ng isang counter sa pamamagitan ng pagsasama ng @Time na agos kasama ang isang @Reaction.

Ang isang @Reaction ay may tatlong bahagi: isang panimulang halaga, isang bagay na dapat panoorin, at isang bagong halaga kapag nagbago ang bagay na iyon.
Dito, nagsisimula tayo sa \0\, pinapanood ang @Time, at nagdaragdag ng isa tuwing tumitik ang orasan:

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 Tuwing isang segundo, @Time ay kumikilos, napapansin ito ng @Reaction gamit ang \∆ Time(1000ms)\, at ang \count\ ay nagiging \count + 1\.
Ang \→ ''\ sa dulo ay ginagawang text ang numero para @Phrase ay maipakita ito.

Maaari mong gamitin ang anumang input na gusto mo, hindi lang ang oras. Binibilang ng counter na ito ang bilang ng mga pagpindot sa Button():

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 Sa bawat pagkakataon ang @Button Nagbabago ang stream sa isang pag-click o pag-tap, tumataas ang bilang ng isa.
