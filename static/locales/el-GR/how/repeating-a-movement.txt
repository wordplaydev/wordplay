Επανάληψη μιας κίνησης

Μερικές φορές θέλουμε να κάνουμε έναν χαρακτήρα να κινείται με τον ίδιο τρόπο πολλές φορές! 
Το να γράφουμε τις ίδιες γραμμές ξανά και ξανά γίνεται κουραστικό.

Αντ' αυτού, μπορούμε να χρησιμοποιήσουμε @Sequence με @Phrase για να κάνουμε κάτι να επαναλαμβάνεται πολλές φορές! Πιο συγκεκριμένα,
μπορούμε να χρησιμοποιήσουμε τον αριθμό στο @Sequence και να επιλέξουμε πόσες φορές θα συμβεί ένα σύνολο πόζεων. Για παράδειγμα, 
εδώ έχουμε μια μπάλα μπάσκετ που αναπηδά πάνω-κάτω δύο φορές. 

\
Πλατό([
	Φράση('🏀' μπαίνοντας: Αλληλουχία({
				0%: Στάση(όφσετ: Θέση(y: 0.25m))
				25%: Στάση(όφσετ: Θέση(y: 0m))
				50%: Στάση(όφσετ: Θέση(y: -0.25m))
				75%: Στάση(όφσετ: Θέση(y: 0m))
				100%: Στάση(όφσετ: Θέση(y: 0.25m))} κόμης:2x διάρκεια:2s))
])
\

animate-phrase, shake-phrase
