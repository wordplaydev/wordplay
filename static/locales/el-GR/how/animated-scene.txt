Δημιούργησε μια κινούμενη σειρά σκηνών

Μερικές φορές θέλουμε να πούμε ιστορίες, να δείξουμε στίχους ή να ζωντανέψουμε ποιήματα.
Για να το κάνουμε αυτό, μπορούμε να χρησιμοποιήσουμε @Scene και @Phrase μαζί, για να δείξουμε μια ακολουθία.

Για παράδειγμα, ας φανταστούμε ότι θέλουμε να ζωντανέψουμε το μικρό παιδικό ποιηματάκι, «Jack be Nimble».
Θα μπορούσαμε να φτιάξουμε ένα @Scene που έχει κάθε στίχο ως @Phrase, και ρυθμίζοντας το @Phrase/duration κάθε στίχου, το @Scene θα προχωρούσε όταν τελείωνε κάθε φράση.

\
Scene([
  Phrase(«Ο Τζακ να 'ναι σβέλτος» διάρκεια: 1s)
  Phrase(«Ο Τζακ να 'ναι γρήγορος» διάρκεια: 1s)
  Phrase('Ο Τζακ πηδάει πάνω από το κερί' διάρκεια: 1s)
])
\

@Scene θα περιμένει να τελειώσει και ένα @Sequence . Ας κάνουμε τον στίχο με το κερί να πηδάει!

\
Scene([
		Phrase(«Ο Τζακ να 'ναι σβέλτος» διάρκεια: 1s)
		Phrase(«Ο Τζακ να 'ναι γρήγορος» διάρκεια: 1s)
		Phrase('Ο Τζακ πηδάει πάνω από το κερί' μπαίνοντας: Sequence.bounce(διάρκεια: 1s))
	])
\

@Scene μπορεί επίσης να πάρει μια @Group κειμένου, και θα περιμένει να τελειώσει η κίνηση όλου του περιεχομένου της.

\
Scene([
		Group(Stack() [
      Phrase(«Ο Τζακ να 'ναι σβέλτος»)
		  Phrase(«Ο Τζακ να 'ναι γρήγορος»)
    ] διάρκεια: 2s)
		Phrase('Ο Τζακ πηδάει πάνω από το κερί' μπαίνοντας: Sequence.bounce(διάρκεια: 1s))
	])
\

 Μερικές φορές ένα ποίημα πρέπει να συνεχίζεται. @Scene/loop φέρνει το @Scene πίσω στο πρώτο του @Phrase αφού τελειώσει το τελευταίο, ώστε να λέγεται ξανά και ξανά από την αρχή.

\
Scene([
		Phrase(«Ο Τζακ να 'ναι σβέλτος» διάρκεια: 1s)
		Phrase(«Ο Τζακ να 'ναι γρήγορος» διάρκεια: 1s)
		Phrase('Ο Τζακ πηδάει πάνω από το κερί' διάρκεια: 1s)
	] βρόχος: ⊤)
\

 Σημείωση: ένα @Scene ξαναγυρίζει στην αρχή μόνο αν κάτι στη λίστα περίμενε πραγματικά.
Μια λίστα όπου κάθε @Phrase είχε @Phrase/duration ίσο με \0s\ θα γύριζε όσο πιο γρήγορα μπορούσε ο υπολογιστής, οπότε σταματάει στο τέλος αντί να συνεχίζει.
