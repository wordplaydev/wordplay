Παρακολούθησε την κατάσταση του παιχνιδιού

Τα περισσότερα παιχνίδια παρακολουθούν πολλά πράγματα καθώς προχωράει το παιχνίδι: πόντοι, θέσεις παικτών και άλλες λεπτομέρειες είναι όλα σημαντικά.Κάθε φορά που υπάρχει μια είσοδος, αυτή η κατάσταση αλλάζει, και τότε θέλουμε να δείξουμε νέο αποτέλεσμα, ως απάντηση.

Ένα γενικό μοτίβο για κάθε παιχνίδι κάνει τρία πράγματα:

• Ορίζει μια δομή δεδομένων κατάστασης παιχνιδιού, για να αποθηκεύει όλη την κατάσταση του παιχνιδιού• Ορίζει μια αντίδραση που φτιάχνει μια νέα κατάσταση παιχνιδιού με βάση την προηγούμενη κατάσταση παιχνιδιού, κάθε φορά που υπάρχει νέα είσοδος• Φτιάχνει ένα  @Stage  με  @Group  και  @Phrase  για να δείξει την κατάσταση του παιχνιδιού

Για παράδειγμα, ας φανταστούμε ένα απλό παιχνίδι όπου πληκτρολογείς μυστικές λέξεις σε ένα κουτί κειμένου, και παίρνεις έναν πόντο κάθε φορά που μαντεύεις μια μυστική λέξη:

\•Game(secrets•[''] points•#)
state: Game(['γάτα' 'σκύλος'] 0) … state.secrets.has(
		Chat()
	) … state.points:state.points + 1
Stage(
	state.points = state.secrets.length() ? [
			Phrase("κέρδισες!")
		] [
			Group(
				Stack()
				[
					Phrase("μάντεψε τις μυστικές μου λέξεις")
					Phrase(
						`\state.secrets.length() - state.points\ περισσότερα μυστικά`
					)
				]
			)
		]
)\

Ας το αναλύσουμε.

• Η πρώτη γραμμή, \•παιχνίδι(μυστικά•[''] πόντοι•#)\ λέει, /Φτιάξε μια δομή δεδομένων που λέγεται \Game\ η οποία αποθηκεύει μια λίστα με μυστικά και πόντους/. Το \[
	''
]\ σημαίνει /μια λίστα με οποιονδήποτε αριθμό λέξεων/. Αν ήθελες αντί για αυτό μια λίστα με ακριβή μήκος, μπορείς να ονομάσεις έναν τύπο για κάθε θέση μέσα σε αυτήν: \[
	#'']\ είναι μια λίστα με δύο πράγματα, έναν αριθμό και μετά μια λέξη.• Η δεύτερη γραμμή λέει /Η κατάσταση του παιχνιδιού ξεκινά με μια λίστα μυστικών λέξεων και μηδέν πόντους. Κάθε φορά που το \Κουβέντα\ αλλάζει, αν η λέξη που δόθηκε είναι στη λίστα μυστικών, τότε φτιάξε μια νέα κατάσταση παιχνιδιού με τους πόντους αυξημένους κατά ένα/.• Κάθε φορά που το πρόγραμμα υπολογίζει ξανά (όταν το \Κουβέντα\ αλλάζει), δείξε μια σκηνή. Αν ο αριθμός των πόντων είναι ίσος με τον αριθμό των μυστικών, δείξε μια νικηφόρα σκηνή. Αν όχι, δείξε ένα μήνυμα και τον αριθμό των μυστικών που απομένουν.

Αυτό το παράδειγμα έχει κάποια προβλήματα:

• Αν κάποιος μαντέψει μια μυστική λέξη πολλές φορές, παίρνει περισσότερους πόντους! Η κατάσταση του παιχνιδιού μας ίσως χρειάζεται να θυμάται και ποιες λέξεις δόθηκαν ήδη, ώστε κάθε λέξη να μετράει το πολύ δύο φορές.• Αν ο παίκτης γράψει πολλές λέξεις μαζί, πρέπει να μετρήσει;

Πιο έξυπνες καταστάσεις παιχνιδιού και ενημερώσεις παιχνιδιού θα μας βοηθούσαν να χειριστούμε αυτές τις περιπτώσεις.
