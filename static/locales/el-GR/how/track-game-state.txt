Παρακολούθησε την κατάσταση του παιχνιδιού

Τα περισσότερα παιχνίδια παρακολουθούν πολλά πράγματα καθώς εξελίσσονται: πόντοι, θέσεις παικτών και άλλες λεπτομέρειες είναι όλα σημαντικά.
Κάθε φορά που υπάρχει κάποια είσοδος, αυτή η κατάσταση αλλάζει, και τότε θέλουμε να δείξουμε νέο αποτέλεσμα, ως απάντηση.

Ένα γενικό μοτίβο για κάθε παιχνίδι κάνει τρία πράγματα:

• Όρισε μια δομή δεδομένων κατάστασης παιχνιδιού, για να αποθηκεύεις όλη την κατάσταση του παιχνιδιού
• Όρισε μια αντίδραση που φτιάχνει μια νέα κατάσταση παιχνιδιού με βάση την προηγούμενη κατάσταση, κάθε φορά που υπάρχει νέα είσοδος
• Φτιάξε ένα @Stage με @Group και @Phrase για να δείχνεις την κατάσταση του παιχνιδιού

Για παράδειγμα, ας φανταστούμε ένα απλό παιχνίδι όπου πληκτρολογείς μυστικές λέξεις σε ένα κουτί κειμένου, και παίρνεις έναν πόντο κάθε φορά που μαντεύεις μια μυστική λέξη:

\
•Game(secrets•[''] points•#)

state: Game(['γάτα' 'σκύλος'] 0) … state.secrets.has(Chat()) … state.points: state.points + 1

Stage(
    state.points = state.secrets.length() ? 
        [ Phrase("κέρδισες!")]
        [ Group(Stack() [ Phrase("μάντεψε τις μυστικές μου λέξεις") Phrase(`\state.secrets.length() - state.points\ περισσότερα μυστικά`)])]
)
\

 Ας το αναλύσουμε.

• Η πρώτη γραμμή, \•παιχνίδι(μυστικά•[''] πόντοι•#)\ λέει, / Φτιάξε μια δομή δεδομένων που λέγεται \Game\ που αποθηκεύει μια λίστα με μυστικά και πόντους /. Το \['']\ σημαίνει / μια λίστα με οποιονδήποτε αριθμό λέξεων /. Αν ήθελες αντί γι' αυτό μια λίστα με ακριβές μήκος, μπορείς να ονομάσεις έναν τύπο για κάθε θέση της: \[# '']\ είναι μια λίστα με δύο πράγματα, έναν αριθμό και μετά μια λέξη.
• Η δεύτερη γραμμή λέει / Η κατάσταση του παιχνιδιού ξεκινά με μια λίστα μυστικών και μηδέν πόντους. Κάθε φορά που αλλάζει το \Κουβέντα\ , αν η λέξη που δόθηκε βρίσκεται στη λίστα μυστικών, τότε φτιάξε μια νέα κατάσταση παιχνιδιού με τους πόντους αυξημένους κατά ένα /.
• Κάθε φορά που το πρόγραμμα επανεκτελείται (όταν αλλάζει το \Κουβέντα\ ), δείξε μια σκηνή. Αν ο αριθμός των πόντων είναι ίσος με τον αριθμό των μυστικών, δείξε μια νικηφόρα σκηνή. Αν όχι, δείξε ένα μήνυμα και τον αριθμό των μυστικών που απομένουν.

Αυτό το παράδειγμα έχει κάποια προβλήματα:

• Αν μαντέψουν μια μυστική λέξη πολλές φορές, παίρνουν περισσότερους πόντους! Η κατάσταση του παιχνιδιού μας μπορεί να χρειάζεται επίσης να θυμάται τι μαντεύτηκε, ώστε κάθε λέξη να μετράει μόνο δύο φορές.
• Αν ο παίκτης δώσει πολλές λέξεις, θα πρέπει να μετράει;

Πιο έξυπνες καταστάσεις παιχνιδιού και ενημερώσεις παιχνιδιού θα μας βοηθούσαν να χειριστούμε αυτές τις περιπτώσεις.
