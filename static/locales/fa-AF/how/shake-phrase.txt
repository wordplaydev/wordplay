یک شخصیت را بلرزان

گاهی خوب است یک شخصیت طوری نشان داده شود که انگار می‌لرزد.چند راه برای انجام این کار وجود دارد.

می‌توانیم از  @Phrase/offset  همراه با  @Random  و  @Time  استفاده کنیم تا این کار انجام شود.

\offset: 0m … ∆ Time() … Random(-0.1m 0.1m)
Phrase('سلام' فاصله: Place(offset 0m))\

این کار یک ارزش به نام \offset\ می‌سازد که هر بار ساعت تیک می‌زند، به یک ارزش تصادفی نو تغییر می‌کند.سپس، از آن جابه‌جایی استفاده می‌کند تا  @Phrase  را به همان اندازه جابه‌جا شده نشان دهد.

اگر می‌خواستیم لرزش را دقیق‌تر کنترل کنیم، می‌توانستیم از یک  @Sequence  استفاده کنیم تا یک انیمیشن لرزش تصادفی و تکرارشونده بسازیم.

\Phrase(
	'سلام'
	درحالاستراحت: Sequence(
		{
			0%: Pose(فاصله: Place(Random(-.2m .2m)))
			15%: Pose(فاصله: Place(Random(-.2m .2m)))
			60%: Pose(فاصله: Place(Random(-.2m .2m)))
			75%: Pose(فاصله: Place(Random(-.2m .2m)))
		}
		0.1s
	)
)\

این مثال فقط یک‌بار ارزش‌های تصادفی را انتخاب می‌کند، اما آن‌ها را به یک دنبالهٔ تکرارشونده تبدیل می‌کند.
