Wähle zufällig etwas aus einer Liste aus

Möchten Sie, dass Ihr Projekt Sie bei jeder Ausführung überrascht? Erstellen Sie eine Liste mit Optionen und wählen Sie eine davon aus. @Random Die 

@Random kann uns eine Zufallszahl geben, und eine Liste kann mit einer Zahl abgefragt werden mit \[n]\ kombinieren.
Setze sie zusammen, um ein zufälliges Emoji auszuwählen:

\
emojis: ['🌈' '🌟' '🎈' '🦄' '🍩']
Phrase(emojis.random())
\

 Du kannst auch @Random mit zwei Zahlen benutzen. Das wählt eine ganze Zahl zwischen ihnen aus.
Um zum Beispiel jede Sekunde ein / neues / zufälliges Emoji auszuwählen, mische @Time und ein @Reaction zu verwandeln:

\
emojis: ['🌈' '🌟' '🎈' '🦄' '🍩']
pick: emojis[1] … ∆ Time(1000ms) … emojis[Random(1 emojis.length())]
Phrase(pick)
\

 Jeder Tick von @Time, Die @Reaction wählt eine neue Überraschung.
