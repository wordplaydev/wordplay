સમય પસાર થાય ત્યાં સુધી ગણતરી કરો

ઘણા પ્રોજેક્ટને એવી કોઈ વસ્તુની જરૂર હોય છે જે સમય સાથે વધે — જેમ કે ટાઈમર, સ્કોર, અથવા કાઉન્ટડાઉન.
આપણે @Time સ્ટ્રીમને @Reaction સાથે જોડીને એક કાઉન્ટર બનાવી શકીએ.

એક @Reaction ના ત્રણ ભાગ છે: એક શરૂઆતનું મૂલ્ય, જોવા માટેની એક વસ્તુ, અને તે વસ્તુ બદલાય ત્યારે એક નવું મૂલ્ય.
અહીં, આપણે \0\ થી શરૂ કરીએ છીએ, @Time ને જોઈએ છીએ, અને દર વખતે ઘડિયાળ ટિક કરે ત્યારે એક ઉમેરીએ છીએ:

\
count: 0 … ∆ Time(1000ms) … count + 1
Phrase(count → '')
\

 દર સેકન્ડે, @Time ચાલુ થાય છે, @Reaction તેને \∆ Time(1000ms)\ સાથે નોંધે છે, અને \count\ બની જાય છે \count + 1\ સાથે જોડીને એક કાઉન્ટર બનાવી શકીએ.
આ \→ ''\ અંતે નંબરને લખાણમાં ફેરવે છે જેથી @Phrase તેને બતાવી શકે.

તમે ઇચ્છો તે કોઈપણ ઇનપુટનો ઉપયોગ કરી શકો છો, ફક્ત સમયનો જ નહીં. આ કાઉન્ટર બટન() દબાવવાની સંખ્યા ગણે છે:

\
count: 0 … ∆ Button() … count + 1
Phrase(count → '')
\

 દરેક વખતે @Button એક ક્લિક કે ટેપથી સ્ટ્રીમ બદલાય છે, ગણતરી એકથી વધે છે.
