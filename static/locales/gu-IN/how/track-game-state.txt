રમતની સ્થિતિનો હિસાબ રાખો

મોટા ભાગની રમતોમાં, રમત આગળ વધે તેમ ઘણી બાબતોનો હિસાબ રખાય છે: પોઈન્ટ, ખેલાડીની જગ્યા, અને બીજી વિગતો બધું જ મહત્વનું છે.જ્યારે પણ કોઈ ઇનપુટ આવે, ત્યારે એ સ્થિતિ બદલાય છે, અને પછી આપણે તેના જવાબમાં નવું આઉટપુટ બતાવવા માંગીએ છીએ.

કોઈ પણ રમત માટેની સામાન્ય રીત ત્રણ કામ કરે છે:

• આખી રમતની સ્થિતિ સંગ્રહવા માટે એક રમત-સ્થિતિ ડેટા સ્ટ્રક્ચર બનાવો• જ્યારે પણ નવું ઇનપુટ આવે ત્યારે પહેલાની રમત-સ્થિતિ પરથી નવી રમત-સ્થિતિ બનાવતું એક રિએક્શન બનાવો• એક  @Stage  સાથે  @Group  અને  @Phrase  બનાવો જેથી રમતની સ્થિતિ બતાવી શકાય

દાખલા તરીકે, એક સાદી રમતની કલ્પના કરીએ જેમાં ટેક્સ્ટ બોક્સમાં ગુપ્ત શબ્દો ટાઈપ કરવાના હોય, અને દરેક વખતે ગુપ્ત શબ્દ સાચો પડે ત્યારે એક પોઈન્ટ મળે:

\•Game(secrets•[''] points•#)
state: Game(['બિલાડી' 'કૂતરો'] 0) … state.secrets.has(Chat()) … state.points:state.points + 1
Stage(
	state.points = state.secrets.length() ? [
			Phrase("તમે જીતી ગયા!")
		] [
			Group(
				Stack()
				[
					Phrase("મારા ગુપ્ત શબ્દો ધારો")
					Phrase(
						`\state.secrets.length() - state.points\ વધુ ગુપ્ત શબ્દો`
					)
				]
			)
		]
)\

ચાલો આને સમજીએ.

• પહેલી લીટી, \•રમત(રહસ્યો•[''] પોઇન્ટ•#)\ કહે છે, /એક ડેટા સ્ટ્રક્ચર બનાવો, જેનું નામ \Game\ છે, જે ગુપ્ત શબ્દોની યાદી અને પોઈન્ટ સંગ્રહે છે/. આ \[
	''
]\ નો અર્થ થાય છે/ગમે તેટલા શબ્દોની યાદી/. જો તમારે તેના બદલે ચોક્કસ લંબાઈની યાદી જોઈતી હોય, તો તમે તેમાંની દરેક જગ્યા માટે એક પ્રકાર જણાવી શકો છો: \[
	#'']\ એ બે વસ્તુઓની યાદી છે, પહેલા એક નંબર પછી એક શબ્દ.• બીજી લીટી કહે છે /રમતની સ્થિતિ ગુપ્ત શબ્દોની યાદી અને શૂન્ય પોઈન્ટથી શરૂ થાય છે. દર વખતે \ચેટ\ બદલાય છે, જો દાખલ કરેલો શબ્દ ગુપ્ત શબ્દોની યાદીમાં હોય, તો પોઈન્ટ એકથી વધારીને નવી રમતની સ્થિતિ બનાવો/.• દર વખતે પ્રોગ્રામ ફરીથી ગણતરી કરે છે (જ્યારે \ચેટ\ બદલાય છે), એક સ્ટેજ બતાવો. જો પોઈન્ટની સંખ્યા ગુપ્ત શબ્દોની સંખ્યા બરાબર હોય, તો જીતનો સ્ટેજ બતાવો. જો નહીં, તો એક સંકેત અને બાકી રહેલા ગુપ્ત શબ્દોની સંખ્યા બતાવો.

આ ઉદાહરણમાં કેટલીક સમસ્યાઓ છે:

• જો તેઓ એક ગુપ્ત શબ્દ ઘણી વખત અંદાજે, તો તેમને વધુ પોઈન્ટ મળે છે! આપણી રમતની સ્થિતિએ કદાચ એ પણ યાદ રાખવું જોઈએ કે શું અંદાજવામાં આવ્યું હતું, જેથી દરેક શબ્દ ફક્ત બે વાર જ ગણાય.• જો ખેલાડી ઘણા શબ્દો દાખલ કરે, તો શું તે ગણાવું જોઈએ?

વધુ સારી રમતની સ્થિતિઓ અને રમતના અપડેટ આપણને આ પરિસ્થિતિઓ સંભાળવામાં મદદ કરશે.
