Ge varje bokstav sin egen färg

En @Phrase kan ge varje tecken en egen @Pose med @Phrase/poses.
Det första tecknet får den första posen, det andra tecknet får den andra, och när posene tar slut börjar de om från den första.

Här är en festtext där tre färger turas om:

\
Fras(
	'party time!'
	ansikte: 'Luckiest Guy'
	poser: [
		Pose(färg: Färg(25% 70 250°))
		Pose(färg: Färg(50% 80 300°))
		Pose(färg: Färg(58% 90 60°))
	]
)
\

 Mellanslag räknas också som tecken, så färgerna fortsätter att turas om mellan orden.
Färgerna skiljer sig både i ljushet och i nyans, så att personer som ser färger annorlunda ändå kan se skillnad på dem.

Poser kan göra mer än att ändra färg. Varje tecken kan luta, växa, tonas ut och röra sig runt sin egen mitt, så vi kan få bokstäverna att studsa:

\
Fras(
	'bounce'
	ansikte: 'Luckiest Guy'
	poser: [
		Pose(färg: Färg(25% 70 250°) rotation: -10° offset: Plats(0m 0.1m))
		Pose(färg: Färg(58% 90 60°) rotation: 10° opacitet: 0.6)
	]
)
\

 Poser fungerar också med formaterad text, och precis som andra indata kan de ändras beroende på andra värden.
Det här utpressningsbrevet väljer en ny lutning var fjärde sekund.

\
tilt: 0° … ∆ Tid(250ms) … Slumpmässig(-15° 15°)
Fras(
	`*ransom* /note/`
	ansikte: 'Courier Prime'
	poser: [
		Pose(rotation: tilt offset: Plats(0m 0.05m))
		Pose(rotation: -tilt skala: 1.2)
		Pose(rotation: tilt ÷ 2 offset: Plats(0m -0.05m))
	]
)
\
