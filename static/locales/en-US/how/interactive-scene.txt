Create an interactive series of scenes

Sometimes we want to tell stories that wait for the viewer to do something before going to the next content.

To do this, we can use a @Scene, but put @Boolean values between the content we want to show. For example, here's a click will advance to each next content, using a @Button:

\
Scene([
		Phrase('click me')
		Button()
		Phrase('click me again' duration: 1s)
		Button()
		Phrase('no really, click me as hard as you can!!' duration: 1s)
		Button()
		Phrase('have you clicked me yet?' duration: 1s)
	])
\

The @Scene shows the first @Phrase, then waits for the @Button to be true, and once it is, it advances to the next @Phrase.

You can use anything you want to advance, as long as it's either true or false. 
For example, we could use our voice! 
If we yell loud enough, the scene will advance:

\
Scene([
		Phrase('is anyone there?')
		Volume() > .5
		Phrase("I can't hear you, say again?" duration: 1s)
		Volume() > .7
		Phrase('louder please...' duration: 1s)
		Volume() > .9
		Phrase('oh, hi!' duration: 1s)
	])
\

When every @Phrase should wait for the same thing, @Scene/until says it once instead of writing it between each one. This does what the first example above does:

\
Scene([
		Phrase('click me')
		Phrase('click me again' duration: 1s)
		Phrase('no really, click me as hard as you can!!' duration: 1s)
		Phrase('have you clicked me yet?' duration: 1s)
	] until: Button())
\

Write a @Boolean in the list when the waits are /different/, as in the yelling example, and use @Scene/until when they're all the same.
You can use both: a @Boolean in the list is a wait of its own, on top of the one @Scene/until asks for.

Note: @Scene/until waits /after/ each @Phrase has had its @Phrase/duration, not instead of it.

If you'd rather the @Scene never moved on its own, and went only where you sent it, use @Scene/pause with @Scene/step:

\
key: Key()
Scene([
		Phrase('one')
		Phrase('two')
		Phrase('three')
	] pause step: ∆ key ? ((key = 'ArrowLeft') ? -1 (key = 'ArrowRight') ? 1 ø) ø)
\

@Scene/step moves by a number of @Phrase — \1\ forward, \-1\ back — and stops at the ends for you.
@Scene/go is the same idea said as a place instead of a distance: the number of the @Phrase you want, counting from 1, or the @Phrase/name you gave it.
