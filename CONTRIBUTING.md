Learn how to contribute on our [project wiki](https://github.com/wordplaydev/wordplay/wiki).

## Formatting

All code is formatted with [Prettier](https://prettier.io/) ([.prettierrc.json](.prettierrc.json)), and CI rejects PRs that aren't. You shouldn't normally have to think about this: `npm install` sets up a pre-commit hook that auto-formats the files you commit, and the recommended VS Code settings format on save. If CI's formatting check does fail, run `npm run format` and commit the result.
